# FBX Test Files

This directory contains test fixture files for FBX classification tests:

- `model.fbx` - FBX file with 3D mesh data (should be classified as MODEL)
- `animation-only.fbx` - FBX file with animation data only (should be classified as ANIMATION)  
- `model-with-clips.fbx` - FBX file with both mesh and animation data (should be classified as MODEL)
