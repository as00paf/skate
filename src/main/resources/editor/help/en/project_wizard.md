# Project Wizard

The Project Wizard creates a new project: a folder with everything a new game needs to start, including a first scene.

## What it is

A **project** is a normal folder on your computer. The wizard asks for two things:

- **Project Name**: the name of your game. Some characters are not allowed in folder names: `< > : / \ | ? *`.
- **Location**: the folder in which the project folder is created.

Below the fields, the wizard tells you whether the name and location are valid, and shows the folders it will create.

## How to use it

1. Choose **File > New Project**, or click **New Project** in [Switch Project](project_switcher.md).
2. Type a **Project Name**.
3. Click **Browse...** to choose the **Location**. A green message means the folder can be used.
4. Click **Create Project**, or press **Enter**. The editor creates the folder and opens the new project.
5. Click **Cancel**, or press **Esc**, to close the wizard without creating anything.
6. If you already have a project, click **Open Project** instead.

After creating the project, read [Getting started](getting_started.md) for your first steps.
