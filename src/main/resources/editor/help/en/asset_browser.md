# Asset Browser

The Asset Browser is the shelf of things you can put in your scenes: 3D models, textures, sounds, animations and prefabs. It shows them by type, with previews, so you can find them without knowing which folder they live in.

## What it is

An **asset** is a file your game uses. The Asset Browser lists the assets of the open project in tabs by type and has a search box at the top. Unlike the [Project](project.md) window, it hides files that are not assets, such as settings files.

A **prefab** is a saved object, with all its components, that you can place again and again.

## How to use it

1. Pick a tab, or type part of a name in the search box.
2. Drag an asset into the [Game Viewport](game_viewport.md) or the [Scene Hierarchy](hierarchy.md) to place it in the scene.
3. Drag a texture, sound or animation onto an object or onto a field in [Properties](properties.md) to use it there. An animation needs an object with an **Animator**.
4. Right-click an asset for more actions:
   - **Spawn in Scene** places a prefab in the current scene.
   - **Apply to Selected** uses the asset on the selected object.
   - **Add to Favorites** keeps it at hand.
   - **Show in Folder** opens its folder in your file explorer.
   - **Open in External Editor** opens it in another program, such as a paint program.
   - **Rename** and **Delete** change the file itself.
5. Every placement can be undone with **Ctrl+Z**.

To get new free assets, use the [Asset Store](asset_store.md). To turn a video into an animation, use [Video to Animation](video_to_animation.md).
