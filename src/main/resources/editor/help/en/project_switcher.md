# Switch Project

Switch Project opens another of your projects. It appears when you click the project name in the menu bar, and when the editor starts without a project.

## What it is

A **project** is the folder that holds one game. You can have several projects, but the editor works on one at a time. The window lists your **recent projects**, newest first, with their folder, and offers two buttons:

- **Open Project**: choose a project file anywhere on your computer.
- **New Project**: create a new project with the [Project Wizard](project_wizard.md).

## How to use it

1. Click the project name in the menu bar, or choose **File > Open Project**.
2. Click a recent project to open it.
3. If the project is not in the list, click **Open Project** and pick its project file.
4. To start a new game, click **New Project**.
5. Press **Esc** to close the window without changing anything.

The editor asks you to save unsaved changes before it closes the current project. A recent project marked as not found has been moved or deleted.
