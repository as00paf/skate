# Search Everywhere

Search Everywhere finds anything in the editor by name: an object in the scene, an asset, a component or an editor action. If you do not know where something is, start here.

## What it is

It is a small search box that appears over the editor. As you type, it lists matching results grouped by kind:

- **GameObjects** in the open scene;
- assets: **Textures**, **Models**, **Animations**, **Sounds**, **Scripts** and **Prefabs**;
- **Components** on the objects;
- **Actions**, such as Save Scene, Play, Create Light or Duplicate.

When the box is empty it shows your **Recent Searches**.

## How to use it

1. Press **Ctrl+P**, choose **Edit > Search Anywhere...**, or click the search box in the title bar.
2. Type a few letters. You do not need the whole name.
3. Move through the results with the **Up** and **Down** arrows.
4. Press **Enter** to open the result: select the object, open the asset or run the action.
5. Press **Esc**, or click outside, to close it.

Some actions only exist here. For example, type `test input` to open the input test.
