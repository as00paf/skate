# Changer de projet

Changer de projet ouvre un autre de vos projets. La fenêtre apparaît quand vous cliquez sur le nom du projet dans la barre de menus, et quand l'éditeur démarre sans projet.

## Ce que c'est

Un **projet** est le dossier qui contient un jeu. Vous pouvez avoir plusieurs projets, mais l'éditeur travaille sur un seul à la fois. La fenêtre liste vos **projets récents**, du plus récent au plus ancien, avec leur dossier, et propose deux boutons :

- **Ouvrir un projet** : choisir un fichier de projet n'importe où sur votre ordinateur.
- **Nouveau projet** : créer un nouveau projet avec l'[Assistant de projet](project_wizard.md).

## Comment l'utiliser

1. Cliquez sur le nom du projet dans la barre de menus, ou choisissez **Fichier > Ouvrir un projet**.
2. Cliquez sur un projet récent pour l'ouvrir.
3. Si le projet n'est pas dans la liste, cliquez sur **Ouvrir un projet** et choisissez son fichier de projet.
4. Pour commencer un nouveau jeu, cliquez sur **Nouveau projet**.
5. Appuyez sur **Échap** pour fermer la fenêtre sans rien changer.

L'éditeur vous demande d'enregistrer les changements avant de fermer le projet courant. Un projet récent marqué **Introuvable** a été déplacé ou supprimé.
