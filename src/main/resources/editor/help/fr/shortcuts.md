# Raccourcis clavier

Les raccourcis font gagner du temps, mais vous n'êtes jamais obligé de les utiliser : chaque action existe aussi dans un menu ou sous forme de bouton. Cette page liste les touches par défaut. Certains raccourcis ne marchent que dans une fenêtre précise, comme la Vue du jeu ou la Hiérarchie de la scène.

## Général

- **Ctrl+Z** : annuler la dernière action.
- **Ctrl+Y** ou **Ctrl+Maj+Z** : rétablir une action que vous venez d'annuler.
- **Ctrl+X**, **Ctrl+C**, **Ctrl+V** : couper, copier et coller la sélection.
- **Ctrl+N** : créer une nouvelle scène.
- **Ctrl+S** : enregistrer la scène courante.
- **Ctrl+Maj+S** : enregistrer la scène courante sous un autre nom.
- **Ctrl+O** : ouvrir un projet.
- **Ctrl+P** : ouvrir la [Recherche globale](search.md).
- **F5** : lancer ou arrêter le mode Jeu.
- **F12** : passer l'éditeur en plein écran et revenir.
- **Échap** : désélectionner l'objet courant.

## Se déplacer dans la Vue du jeu

- **Bouton du milieu + glisser** : regarder autour de soi.
- **W**, **A**, **S**, **D** : avancer, aller à gauche, reculer et aller à droite.
- **Espace** : monter.
- **Maj gauche** : descendre.
- **Molette** : zoomer et dézoomer.
- **Origine** (Home) : remettre la caméra à la vue de départ.
- **F** : cadrer la caméra sur l'objet sélectionné.

## Gizmos

- **1** : outil de sélection.
- **2** : outil de déplacement.
- **3** : outil de rotation.
- **4** : outil d'échelle.
- **M** : outil de mesure.

## Hiérarchie de la scène

- **Inser** : créer un objet vide.
- **Suppr** : supprimer l'objet sélectionné.
- **Ctrl+D** : dupliquer l'objet sélectionné.
- **F2** : renommer l'objet sélectionné.
- **V** : montrer ou cacher l'objet sélectionné.
- **L** : verrouiller ou déverrouiller l'objet sélectionné.
- **Haut** et **Bas** : parcourir la liste.
- **Origine** et **Fin** : aller au premier ou au dernier objet.

## Console

- **Ctrl+C** : copier les lignes sélectionnées quand la [Console](console.md) a le focus.

## Éditeur de scripts

- **Ctrl+S** : enregistrer le script et le recharger s'il tourne.
- **Ctrl+F** : chercher du texte dans le script courant.
- **Ctrl+H** : chercher et remplacer du texte.
- **Ctrl+G** : aller à un numéro de ligne.

## Changer les raccourcis

Ouvrez les [Raccourcis clavier](keybindings.md) pour choisir une autre touche pour une action. Si deux actions utilisent la même touche dans le même contexte, l'éditeur affiche un avertissement de conflit. Réinitialisez une action ou toute une catégorie si vous êtes perdu.
