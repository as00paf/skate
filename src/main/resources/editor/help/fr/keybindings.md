# Raccourcis clavier

La fenêtre Raccourcis clavier liste tous les raccourcis de l'éditeur et toutes les commandes de votre jeu, et permet de les changer.

## Ce que c'est

Une **association** relie une entrée (une touche, un bouton de souris, un bouton ou un stick de manette) à une **action** (sauter, avancer, ouvrir la recherche...). La fenêtre a des onglets :

- **Actions de jeu** : les commandes de votre jeu, enregistrées avec le projet. Chaque action peut avoir plusieurs associations, par exemple une touche et un bouton de manette. Les actions sont regroupées par contexte, comme **Jeu**, **Interface** ou **Skateboard**.
- **Raccourcis de l'éditeur** : les touches que vous utilisez dans l'éditeur, comme les outils de gizmo ou Jouer.
- **Raccourcis fixes** : les raccourcis standard comme Ctrl+C. Ils ne peuvent pas être changés.
- **Test** : appuyez sur des touches ou bougez un stick de manette pour voir quelle action se déclenche.

## Comment l'utiliser

1. Ouvrez-la avec **Paramètres > Raccourcis Clavier...**, ou avec le bouton **Raccourcis clavier** des [Paramètres de l'éditeur](editor_settings.md).
2. Tapez dans le champ de recherche pour trouver une action par son nom ou sa touche.
3. Cliquez sur une association, puis appuyez sur la nouvelle touche. Appuyez sur **Échap** ou **Annuler** pour arrêter d'attendre.
4. Utilisez **+** pour ajouter une autre association : une touche du clavier, un bouton de souris ou une entrée de manette.
5. Si l'entrée est déjà utilisée, la fenêtre indique par quelle action. Choisissez **Échanger** pour intervertir les deux associations, ou **Retirer à l'autre** pour enlever l'entrée à l'autre action.
6. **Réinitialiser** remet une action par défaut, la réinitialisation d'un groupe remet tout le groupe, et **Tout réinitialiser** remet tout. **Effacer** retire toutes les associations d'une action.
7. Enregistrez un ensemble d'associations comme **Profil** pour le recharger plus tard, ou utilisez **Copier le JSON** et **Coller le JSON** pour le partager.

Les changements des actions de jeu s'annulent avec **Ctrl+Z**.
