# Recherche globale

La Recherche globale trouve n'importe quoi dans l'éditeur par son nom : un objet de la scène, une ressource, un composant ou une action de l'éditeur. Si vous ne savez pas où se trouve quelque chose, commencez ici.

## Ce que c'est

C'est un petit champ de recherche qui s'affiche par-dessus l'éditeur. Pendant que vous tapez, il liste les résultats regroupés par sorte :

- les **GameObjects** de la scène ouverte ;
- les ressources : **Textures**, **Modèles**, **Animations**, **Sons**, **Scripts** et **Préfabs** ;
- les **Composants** des objets ;
- les **Actions**, comme Enregistrer la scène, Jouer, Créer une lumière ou Dupliquer.

Quand le champ est vide, il montre vos **Recherches récentes**.

## Comment l'utiliser

1. Appuyez sur **Ctrl+P**, choisissez **Éditer > Rechercher partout...**, ou cliquez sur le champ de recherche de la barre de titre.
2. Tapez quelques lettres. Inutile de taper le nom entier.
3. Parcourez les résultats avec les flèches **Haut** et **Bas**.
4. Appuyez sur **Entrée** pour ouvrir le résultat : sélectionner l'objet, ouvrir la ressource ou lancer l'action.
5. Appuyez sur **Échap**, ou cliquez à l'extérieur, pour la fermer.

Certaines actions n'existent qu'ici. Par exemple, tapez `test input` pour ouvrir le test des entrées.
