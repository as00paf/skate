# Projet

La fenêtre Projet est l'explorateur de fichiers de votre jeu. Elle montre les dossiers et fichiers du projet courant, et c'est là que vous rangez les scènes, scripts, textures, modèles et sons.

## Ce que c'est

Un projet est un dossier normal de votre ordinateur. La fenêtre Projet affiche son contenu sous forme d'arbre, avec un champ de recherche en haut et une barre d'état en bas qui compte les fichiers, les dossiers et la taille totale.

Elle n'est pas la même chose que le [Navigateur de ressources](asset_browser.md) : la fenêtre Projet montre tous les fichiers, scripts et fichiers de configuration compris, alors que le Navigateur de ressources montre les ressources prêtes à l'emploi, regroupées par type.

## Comment l'utiliser

1. Tapez dans le champ de recherche pour filtrer l'arbre par nom.
2. Cliquez sur un dossier pour le déplier ou le replier.
3. Double-cliquez sur une scène pour l'ouvrir, sur un script pour l'ouvrir dans l'[Éditeur de scripts](script_editor.md), ou sur un fichier pour lancer son action par défaut.
4. Un clic droit dans le vide propose **Nouveau dossier** et **Nouveau fichier**. Un clic droit sur un fichier ou un dossier propose **Renommer**, **Supprimer**, **Afficher dans l'explorateur**, **Copier le chemin** et, pour les ressources, **Réimporter**.
5. Un clic droit sur une scène ou une ressource permet de l'ajouter à vos favoris. Les favoris sont listés en haut pour un accès rapide.
6. Faites glisser un fichier dans la vue ou sur un champ de composant pour l'utiliser. Par exemple, une texture sur un matériau, ou un son sur une Source audio.
7. Regardez la barre d'état : elle indique combien de fichiers et de dossiers contient le projet et la place qu'ils occupent.

Les fichiers sur le disque font foi. Si vous modifiez un fichier hors de l'éditeur, utilisez l'action d'actualisation ou rouvrez la fenêtre pour voir le changement.
