# A46.0.1.15: Improve Gizmos & Undo/Redo History UI - Implementation Plan

## Executive Summary

Create a new "Command History" editor window that displays the undo/redo stack with visual feedback, allowing users to see their edit history, navigate through commands, and selectively undo/redo operations. Also improve the existing gizmo UI with better visual indicators and shortcuts display.

**Priority:** Medium  
**Estimated Effort:** 8-10 hours  
**Complexity:** Medium  
**Dependencies:** UndoRedoManager, GizmoSystem

---

## Current State Analysis

### Undo/Redo System
- **UndoRedoManager** maintains undo/redo stacks (max 100 commands)
- **Command interface** with `execute()` and `undo()` methods
- **Existing commands:** TransformCommand, CreateGameObjectCommand, DeleteGameObjectCommand
- **No UI** to view command history
- **No way** to see what operations can be undone/redone

### Gizmo System
- **Gizmos:** Translate, Rotate, Scale, Selection, Measure, Pose
- **Toggle via toolbar buttons** in GameViewWindow
- **Keyboard shortcuts:** Q (Select), W (Translate), E (Rotate), R (Scale), M (Measure)
- **No dedicated UI panel** showing active gizmo, settings, or shortcuts

### Window Management
- **EditorWindow** data class manages window instances
- **ImGuiLayer** renders all editor windows
- **EditorMenuBar** has View menu for window visibility toggles
- **Pattern established** for adding new dockable windows

// Accessors for UI
fun getUndoHistory(): List<Command> = undoStack.toList()
fun getRedoHistory(): List<Command> = redoStack.toList()
fun getUndoCount(): Int = undoStack.size
fun getRedoCount(): Int = redoStack.size

// Clear history
fun clear() {
    undoStack.clear()
    redoStack.clear()
}

// Jump to specific state
fun undoTo(index: Int) {
    while (undoStack.size > index && undoStack.isNotEmpty()) {
        undo()
    }
}

    while (redoStack.size > index && redoStack.isNotEmpty()) {
        redo()
    }
}

### Phase 2: Create CommandHistoryWindow (3-4 hours)

**File:** `src/main/kotlin/com/pafoid/skate/editor/windows/CommandHistoryWindow.kt`

**Implementation:**
```kotlin
class CommandHistoryWindow : IWindow, KoinComponent {
    private val undoRedoManager: UndoRedoManager by inject()
    private val stringManager: StringManager by inject()
    private val logger: LoggerService by inject()
    
    private var scrollToBottom = false
    private val undoStackHeight = 200f
    private val redoStackHeight = 150f
    
    override fun imgui(pOpen: ImBoolean?) {
        ImGui.begin(stringManager.getString("window.command_history"), pOpen)
        
        // Toolbar
        renderToolbar()
        
        ImGui.separator()
        
        // Undo History
        renderUndoHistory()
        
        ImGui.separator()
        
        // Redo History
        renderRedoHistory()
        
        ImGui.separator()
        
        // Footer with shortcuts
        renderFooter()
        
        ImGui.end()
    }
    
    private fun renderToolbar() {
        // Undo button
        if (ImGui.button("${Icons.UNDO} Undo")) {
            undoRedoManager.undo()
        }
        ImGui.sameLine()
        
        // Redo button
        if (ImGui.button("${Icons.REDO} Redo")) {
            undoRedoManager.redo()
        }
        ImGui.sameLine()
        
        // Clear button
        if (ImGui.button("${Icons.TRASH} Clear")) {
            undoRedoManager.clear()
        }
    }
    
    private fun renderUndoHistory() {
        val undoStack = undoRedoManager.getUndoHistory()
        
        ImGui.text("${stringManager.getString("lbl.command_history.undo")} (${undoStack.size})")
        
        ImGui.beginChild("UndoHistory", 0f, undoStackHeight)
        
        // Render in reverse (most recent first)
        for (i in undoStack.indices.reversed()) {
            val command = undoStack[i]
            val label = "${i + 1}. ${command.getDisplayName()} (${command.getTargetName()})"
            
            if (ImGui.selectable(label, false)) {
                // Undo to this state
                undoTo(i)
            }
        }
        
        if (scrollToBottom) {
            ImGui.setScrollHereY(1.0f)
            scrollToBottom = false
        }
        
        ImGui.endChild()
    }
    
    private fun renderRedoHistory() {
        val redoStack = undoRedoManager.getRedoHistory()
        
        ImGui.text("${stringManager.getString("lbl.command_history.redo")} (${redoStack.size})")
        
        ImGui.beginChild("RedoHistory", 0f, redoStackHeight)
        
        for (i in redoStack.indices) {
            val command = redoStack[i]
            val label = "${i + 1}. ${command.getDisplayName()} (${command.getTargetName()})"
            
            if (ImGui.selectable(label, false)) {
                // Redo to this state
                redoTo(i)
            }
        }
        
        ImGui.endChild()
    }
    
    private fun renderFooter() {
        ImGui.textColored(0.5f, 0.5f, 0.5f, 1f, 
            "Ctrl+Z: Undo | Ctrl+Y: Redo | Click to jump to state")
    }
    
    private fun undoTo(index: Int) {
        while (undoRedoManager.getUndoCount() > index) {
            undoRedoManager.undo()
        }
    }
    
    private fun redoTo(index: Int) {
        while (undoRedoManager.getRedoCount() > index) {
            undoRedoManager.redo()
        }
    }
}
```

## Performance Considerations

### Command History Window
- **History limit:** Already capped at 100 commands
- **UI rendering:** Only render visible commands (ImGui child window handles this)
- **Click-to-jump:** May execute multiple undo/redo operations (should be fast)

### Memory
- **Command objects:** Already in memory, window just references them
- **No additional storage** needed
