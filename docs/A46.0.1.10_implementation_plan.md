# Implementation Plan - A46.0.1.10: Implement Profiler Graph View

## Goal
Enhance the `ProfilerWindow` with real-time performance graphs to visualize engine performance over time. This will help identify spikes in frame time, physics processing, and memory consumption.

## Requirements
- **Real-time Graphs**: Use `ImGui.plotLines` for rendering.
- **Metrics to Track**:
    - **Frame Time**: Time taken to process a single frame (ms).
    - **FPS**: Frames per second.
    - **Physics Step Time**: Time taken by the physics engine for a single step (ms).
    - **Memory Usage**: Currently used heap memory (MB).
- **History Tracking**: Maintain a buffer of at least 200 frames.
- **Integration**: Update `ProfilerWindow.kt`.
- **Localization**: Use `StringManager` for all UI labels.

## Technical Design

### Data Structure (Coordination with @tech-lead)
To efficiently store and pass data to ImGui, we will use a circular buffer approach using `FloatArray`. This avoids constant array allocations and shifting.

```kotlin
private class PerformanceHistory(val maxSize: Int = 200) {
    val frameTimes = FloatArray(maxSize)
    val fpsValues = FloatArray(maxSize)
    val physicsStepTimes = FloatArray(maxSize)
    val memoryUsage = FloatArray(maxSize)
    
    var currentIndex = 0
    var currentSize = 0

    fun addFrame(frameTime: Float, fps: Float, physicsStep: Float, memory: Float) {
        frameTimes[currentIndex] = frameTime
        fpsValues[currentIndex] = fps
        physicsStepTimes[currentIndex] = physicsStep
        memoryUsage[currentIndex] = memory
        
        currentIndex = (currentIndex + 1) % maxSize
        if (currentSize < maxSize) {
            currentSize++
        }
    }
}
```

### ImGui Rendering
We will use `ImGui.plotLines` which supports a `valuesOffset` parameter. This parameter is perfect for our circular buffer as it tells ImGui where the "oldest" value is.

Example usage:
```kotlin
ImGui.plotLines(
    stringManager.getString("lbl.profiler.frame_time_graph"),
    history.frameTimes,
    history.currentSize,
    history.currentIndex, // valuesOffset
    "${history.frameTimes[if(history.currentIndex == 0) history.maxSize - 1 else history.currentIndex - 1]} ms",
    0f, // scaleMin
    100f, // scaleMax
    0f, 80f // graphSize (width 0 = auto, height 80)
)
```

### Task 2: Data Collection
- In the `imgui()` method of `ProfilerWindow`, collect the following values every frame:
    - `frameTime`: `1000.0f / ImGui.getIO().framerate`
    - `fps`: `ImGui.getIO().framerate`
    - `physicsTime`: `EngineStats.physicsStepTime.get().toFloat() / 1_000_000f`
    - `memoryMB`: `(Runtime.getRuntime().totalMemory() - Runtime.getRuntime().freeMemory()) / 1024 / 1024`.
- Call `history.addFrame(...)` with these values.
