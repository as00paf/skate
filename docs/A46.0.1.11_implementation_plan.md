# Implementation Plan - A46.0.1.11: Redesign Viewport Toolbar

The goal of this task is to improve the layout and positioning of the Viewport Toolbar and the FPS counter in the `GameViewWindow`.

## User Requirements

1. Keep the current buttons and icons.
2. Align buttons to the left instead of centered.
3. Ensure proper spacing between buttons.
4. Fix the vertical positioning: the toolbar starts too far from the top of its container.
5. Relocate the FPS counter: it should be drawn inside the game view (the rendered image area) instead of in the toolbar container area.

## Proposed Changes

### 1. Viewport Toolbar Alignment and Positioning (`GameViewWindow.kt`)

- **Horizontal Alignment**: Change the calculation of `toolbarPosX` in `renderToolbar` to use a fixed offset from the left edge of the viewport area instead of centering it.
- **Vertical Positioning**: Reduce the vertical offset `toolbarPosY` in `renderToolbar` to bring the buttons closer to the top of the toolbar area.
- **Spacing**: Review `TOOLBAR_BUTTON_SPACING` to ensure it is visually consistent with the rest of the editor's UI.

### 2. FPS Counter Relocation (`GameViewWindow.kt`)

- **Positioning**: Update `renderViewportOverlays` to move the `FPS_Overlay` child window.
- **New Position**: The FPS counter should be drawn over the game image. This means its Y coordinate should be at least `windowPos.y + TOOLBAR_HEIGHT + OVERLAY_PADDING`.
- **Alternative**: Consider moving it to the top-right of the viewport for a cleaner look if top-left feels crowded with the now left-aligned toolbar. (Optional, check visual balance).

## Actionable Steps for @software-engineer

1. **Modify `renderToolbar`**:
    - Update `toolbarPosX` to `windowPos.x + OVERLAY_PADDING`.
    - Update `toolbarPosY` to `windowPos.y + 5f` (or a smaller value than current 10f).
    - Ensure `ImGui.setCursorPos` uses these new values.
2. **Modify `renderViewportOverlays`**:
    - Update the position for `FPS_Overlay`.
    - Change `ImGui.setCursorPos(windowPos.x + OVERLAY_PADDING, windowPos.y + OVERLAY_PADDING)` to `ImGui.setCursorPos(windowPos.x + OVERLAY_PADDING, windowPos.y + TOOLBAR_HEIGHT + OVERLAY_PADDING)`.
3. **Verification**:
    - Run the editor and verify that the toolbar is left-aligned.
    - Verify that the toolbar is closer to the top.
    - Verify that the FPS counter is now inside the game image area.
    - Ensure all buttons still function correctly.

## Technical Notes

- The `windowPos` in `GameViewWindow` represents the top-left corner of the aspect-ratio corrected viewport area.
- `TOOLBAR_HEIGHT` is currently 40f.
- The image is drawn from `windowPos.y + TOOLBAR_HEIGHT`.
- The current toolbar buttons are added to a list and rendered in a child window. This logic should be preserved.
