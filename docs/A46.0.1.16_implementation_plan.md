# A46.0.1.16: Render Graph Visualization Window - Implementation Plan

## Executive Summary

Create a new "Render Graph" editor window that visualizes the rendering pipeline, showing render passes, their dependencies, execution order, and performance metrics. This window will help developers understand and debug the rendering pipeline by providing a visual representation of the render graph structure.

**Priority:** Medium-High  
**Estimated Effort:** 10-12 hours  
**Complexity:** Medium-High  
**Dependencies:** RenderGraph, RenderPass, RenderContext

---

## Current State Analysis

### Render Graph Architecture
- **RenderGraph** - Orchestrates render passes with resource dependencies
- **RenderPass** interface - Individual rendering operations (prepare, execute, cleanup)
- **RenderContext** - Provides scene data and resources to passes
- **Existing Passes:**
  - PickingPass - Object selection rendering
  - GeometryPass - Main 3D geometry rendering
  - ShadowPass - Shadow map rendering
  - DebugPass - Debug visualization rendering

### Window Management
- **IWindow** interface for editor windows
- **ImGuiLayer** manages window registration and rendering
- **EditorMenuBar** View menu for window visibility toggles
- **ProfilerWindow** exists as reference for performance visualization

### Current Limitations
- No visual representation of render graph structure
- No way to see pass execution order
- No visibility into pass dependencies
- No per-pass performance metrics
- No way to enable/disable individual passes for debugging

```kotlin
// Pass metadata for visualization
val displayName: String get() = name  // Human-readable name
val description: String get() = ""    // Optional description
val canDisable: Boolean get() = true  // Whether pass can be disabled

// Performance tracking
var executionTimeNs: Long = 0
    private set

var isEnabled: Boolean = true
    private set

// Timing wrapper
fun measureExecutionTime(context: RenderContext) {
    val start = System.nanoTime()
    try {
        execute(context)
    } finally {
        executionTimeNs = System.nanoTime() - start
    }
}

fun toggleEnable() {
    if (canDisable) {
        isEnabled = !isEnabled
    }
}
```

```kotlin
fun getAllPasses(): List<RenderPass> = passes.toList()

fun getPassByName(name: String): RenderPass? {
    return passes.find { it.name == name }
}

// Execute only enabled passes
fun execute(scene: Scene, activeGameObject: GameObject?, hoveredGameObject: GameObject?) {
    val context = RenderContext(...)
    
    // Prepare all nodes
    passes.filter { it.isEnabled }.forEach { it.prepare() }
    
    // Execute only enabled nodes
    passes.filter { it.isEnabled }.forEach { it.execute(context) }
    
    // Cleanup
    passes.forEach { it.cleanup() }
}
```

```kotlin
object RenderGraphNode {
    /**
     * Renders a node box for a render pass.
     *
     * @param pass The render pass to visualize
     * @param isSelected Whether the node is selected
     * @return True if the node was clicked
     */
    fun renderNode(
        pass: RenderPass,
        isSelected: Boolean = false
    ): Boolean {
        var clicked = false
        
        // Node header with pass name
        if (ImGui.collapsingHeader(pass.displayName)) {
            // Show inputs
            if (pass.inputs.isNotEmpty()) {
                ImGui.text("Inputs:")
                pass.inputs.forEach { input ->
                    ImGui.bulletText(input)
                }
            }
            
            // Show outputs
            if (pass.outputs.isNotEmpty()) {
                ImGui.text("Outputs:")
                pass.outputs.forEach { output ->
                    ImGui.bulletText(output)
                }
            }
            
            // Show execution time
            val timeMs = pass.executionTimeNs / 1_000_000f
            ImGui.textColored(
                if (timeMs > 2.0f) 1f else 0.5f,
                if (timeMs > 2.0f) 0f else 1f,
                0f, 1f,
                "⏱️ %.2fms".format(timeMs)
            )
            
            // Enable/disable toggle
            if (pass.canDisable) {
                val enabled = ImBoolean(pass.isEnabled)
                if (ImGui.checkbox("Enabled", enabled)) {
                    pass.toggleEnable()
                    clicked = true
                }
            }
        }
        
        return clicked
    }
```

```kotlin
class RenderGraphWindow : IWindow, KoinComponent {

    private val stringManager: StringManager by inject()
    private val renderer: Renderer by inject()  // To access render graph
    
    private var autoUpdate = true
    private var showPerformance = true
    private var selectedPass: RenderPass? = null
    private var zoomLevel = 1.0f
    private var panOffset = ImVec2(0f, 0f)
    
    // Node layout cache
    private val nodePositions = mutableMapOf<String, ImVec2>()
    
    override fun imgui(pOpen: ImBoolean?) {
        ImGui.begin(stringManager.getString("window.render_graph"), pOpen)
        
        // Toolbar
        renderToolbar()
        
        ImGui.separator()
        
        // Graph visualization area
        ImGui.beginChild("GraphView", 0f, 0f)
        
        if (autoUpdate) {
            refreshGraph()
        }
        
        renderGraphNodes()
        
        ImGui.endChild()
        
        ImGui.separator()
        
        // Status bar
        renderStatusBar()
        
        ImGui.end()
    }
    
    private fun renderToolbar() {
        if (ImGui.button("${Icons.ARROW_ROTATE} Refresh")) {
            refreshGraph()
        }
        
        ImGui.sameLine()
        val autoUpdateBool = ImBoolean(autoUpdate)
        if (ImGui.checkbox("Auto-Update", autoUpdateBool)) {
            autoUpdate = autoUpdateBool.get()
        }
        
        ImGui.sameLine()
        val showPerfBool = ImBoolean(showPerformance)
        if (ImGui.checkbox("Show Perf", showPerfBool)) {
            showPerformance = showPerfBool.get()
        }
        
        ImGui.sameLine()
        if (ImGui.button("${Icons.TRASH} Reset Stats")) {
            resetPerformanceStats()
        }
        
        // Zoom controls
        ImGui.sameLine()
        ImGui.text("Zoom:")
        ImGui.sameLine()
        val zoomArr = floatArrayOf(zoomLevel)
        if (ImGui.sliderFloat("##Zoom", zoomArr, 0.5f, 2.0f, "%.1f")) {
            zoomLevel = zoomArr[0]
        }
    }
    
    private fun renderGraphNodes() {
        val renderGraph = renderer.renderGraph  // Need to expose this
```

- **Pass metadata** - Already in memory
- **No additional allocations** during rendering

## Risk Assessment

| Risk | Impact | Likelihood | Mitigation |
|------|--------|------------|------------|
| Performance overhead from timing | Low | Low | Use nanoTime(), minimal overhead |
| Complex node layout logic | Medium | Medium | Start with simple vertical layout |
| Disabling passes breaks rendering | High | Low | Only allow disabling non-critical passes |
| ImGui drawing limitations | Medium | Low | Use simple boxes, avoid complex curves |
| Thread safety issues | Medium | Low | Access render graph only from render thread |

## Conclusion

This implementation adds a valuable debugging and visualization tool for the rendering pipeline. The Render Graph window provides visibility into pass execution, performance metrics, and allows runtime modification of the pipeline. The implementation follows existing patterns and requires minimal changes to core rendering code.
