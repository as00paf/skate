# EDT-106 — Missing editor UI audit

Status: audit done (read-only), 2026-11-17, by skate-input. No code changed.
Source request: human, Discord 2026-11-17, "Plan all missing editor UI".
Scope: every ECS component, engine or project setting, and asset type that has no editor UI, or only raw fields.
Rule from the task: each domain agent writes the UI for its own back end, and skate-editor reviews it.

## 1. Method

- Components: every `Component` subclass in `engine/` and `game/` (56 classes), checked against
  `ComponentType` (the Add Component menu), the inspector dispatch in `editor/imgui/components/Component.kt`, and
  what the generic `reflectedImgui` can draw.
- Settings: every `*Settings` / `*Config` / `*Tuning` / `*Options` class in `engine/` and `game/`, checked against
  the editor (Project Settings, Editor Settings, file inspectors, dedicated windows).
- Asset types: `editor/data/FileType.kt`, the engine's asset extensions (`skmat`, `skanim`, `skterrain`, `prefab`,
  `.controller.json`, `.character.json`, `.item.json`, …), the Project window double-click handler and the
  `FileInspector` implementations.
- Gaps that an open backlog task already covers are listed under §6 and get no new task.

## 2. What the generic inspector cannot draw

Components without a custom inspector go through `reflectedImgui`. It draws `Int`, `Float`, `Boolean`, `String`
(plus an object picker for `@GameObjectRef`), `Vector2f/3f/4f` and enums. It **hides** without notice:

- lists, maps and arrays (`MutableList<WheelConfig>`, `Map<String, String>`, …);
- nested data classes (`WaterResponse`, `TerrainRecipe`, `AnimatorMaskDef`, …);
- `Quaternionf`, `Texture`, `Matrix4f` and other engine types.

It also shows asset references (`texturePath`, `configPath`, `meshRef`, `materialPath`, `prefabId`, …) as plain
text: no picker, no drag and drop from the Asset Browser, no "missing file" warning.
Colours stored as `Vector3f` show as three numbers (already EDT-102).

Fixing these two things once in the editor removes most of the per-component gaps below, so they come first.

## 3. Components

`Add?` = listed in Add Component. `UI` = custom inspector (C), reflected (R), UI-inspector (U).

| Component | Owner | Add? | UI | Gap |
|---|---|---|---|---|
| Transform, RenderComponent, SpriteRenderer, CameraComponent, the 3 lights, JointComponent, ReverbZone, AudioComponent, Animator, ParticleEmitter | various | yes | C | none beyond §2 (particle `texturePath` is raw text) |
| UI* (Button, Canvas, Element, Image, List, ProgressBar, Slider, Text) | GUI | yes | U | none |
| UIMapComponent, UIMapMarkerComponent | GUI | **no** (not in `ComponentType` nor in the Create UI menu) | U | cannot be added in the editor; `target`, `openButton`, `closeButton` are object names without `@GameObjectRef` |
| RenderComponent | REN | yes | C | no way to change the model/mesh of an existing object |
| RigidBody3D | PHY | yes | R | `collisionLayer` / `collisionMask` are raw ints (no layer names, no matrix) |
| Box/Capsule/Cylinder colliders | PHY | yes | R | no viewport wireframe or handles for the selected collider |
| CustomCollider3D, CompoundHullCollider3D, MeshCollider3D | PHY | yes | R | hull points / vertices hidden; no "generate from mesh"; `meshRef` raw text |
| VehicleComponent | PHY | yes | R | `wheels` list hidden: wheels cannot be added, moved or flagged steer/drive |
| RagdollComponent | PHY | yes | R | only `state`; bone mapping and masses are hard-coded in `RagdollBuilder` (Mixamo only) |
| ScenePhysicsComponent | PHY | yes | R | fine |
| EnvironmentComponent | REN | yes | R | `skyTexture` (sky/HDRI) hidden — no sky picker; wind part is EDT-90 |
| DayNightCycleComponent, GridLines | REN / ECS | yes | R | colours only (EDT-102, ECS-15) |
| WaterComponent | REN | yes | R | EDT-90 |
| TerrainComponent | REN | yes | R | EDT-92, EDT-96, EDT-97 |
| ScriptComponent | SCR | yes | C | `properties` map (script parameters) hidden: values cannot be set per object |
| NativeScriptComponent | SCR / ECS | **yes** | — | code-only (all callbacks transient); adding it from the editor does nothing |
| PlayerController | GPL | yes | R | `behaviorId` raw text (should be a list of registered behaviours), `configPath` raw text, `waterResponse` hidden |
| FollowCamera / FirstPersonCamera | GPL | yes | R | fine (`targetName` has the object picker) |
| CameraCycleComponent | GPL / INP | yes | R | `cameraNames` is a comma-separated text field; `actionId` is raw text (no action picker) |
| CameraFocusComponent | GPL | **no** | R | `targets` list hidden; cannot be added |
| FreeFlyCameraComponent | GPL | **no** | R | cannot be added |
| SkateboardController | GPL | **no** | R | runtime input flags only; fine to keep code-only |
| InputStateComponent | INP | **yes** | R | runtime state shown as editable fields; adding it by hand is meaningless |
| PrefabInstance | ECS | no (by design) | R | `overrides` hidden: no list of overrides, no Apply / Revert to prefab |
| BoneOverride, SkeletonComponent | ANI | yes / no | R | maps and pose hidden; low value (driven by the Animation Editor) |
| NetworkIdentity, NetState, LoopbackPredictionComponent | NET | **no** | R | cannot be added; no net settings UI (multiplayer not user-facing yet) |
| AudioListener, NonPickable | AUD / ECS | yes | — | no fields; fine |

Cross-cutting inspector gaps (EDT):

- The Add Component menu lists raw enum names (`BOX_COLLIDER_3D`), not translated names, has no categories, and
  its search matches only the enum name.
- "Copy component" in the component context menu is disabled (no copy / paste of component values).

## 4. Engine and project settings

| Setting | Owner | Editor UI today | Gap |
|---|---|---|---|
| `PostProcessSettings` (bloom, ACES exposure, gamma, FXAA, SSAO, SSR steps, order) | REN | only the quality preset | **no way to tune post-processing** |
| Collision layers | PHY | none | no layer names, no layer-vs-layer matrix in Project Settings |
| Physics rate, gravity | PHY | Project Settings / ScenePhysics | fine |
| `AudioConfig`, mixer, buses | AUD | Audio Inspector, Mixer | fine |
| `WaterAudioConfig` (splash, ambience) | AUD | none | sounds and volumes not selectable |
| Input actions and contexts | INP | Key Bindings edits bindings of actions defined **in code** | a project cannot define its own actions or contexts in the editor (needed for non-skate games) |
| Dead zones, curves | INP | Project Settings > Input | fine |
| Rumble | INP | none | no way to test a rumble pattern on a pad |
| Control schemes, `TrickInputSettings`, `FlickSettings` | GPL | none (hard-coded in `ControlSchemes`) | trick thresholds cannot be tuned |
| `SkateControllerConfig` (`.character.json`) | GPL | `ConfigFileInspector` | fine |
| `NetConfig`, `PredictionTuning` | NET / GPL | none | deferred until multiplayer is user-facing |
| Export settings | AST | EDT-91 | covered |
| Graphics, display, editor settings | EDT | Project / Editor Settings | fine |

## 5. Asset types

| Asset | Owner | Editor UI today | Gap |
|---|---|---|---|
| Texture (png, jpg, hdr, …) | AST / REN | thumbnails | no import settings (sRGB, filtering, mipmaps, wrap, compression) |

| Scene, `.skanim`, `.controller.json`, `.character.json`, `.blend`, `.skterrain`, `.osm.json` | — | yes / EDT-92 / EDT-71 | covered |
| Input binding profile | INP | Key Bindings | fine |

## 7. Proposed tasks

IDs are the next free ones on 2026-11-17; the lead may renumber. Every UI task: undoable through Commands,
strings in the owner's area file (EN + FR, tooltips), skate-editor reviews.

### EDT (skate-editor) — shared building blocks, do first

- **EDT-107** `P1` Generic inspector draws lists, maps and nested objects.
  `reflectedImgui` draws `List`/`MutableList` (add, remove, reorder), `Map<String, *>` and nested
  `@Serializable` data classes recursively, with undo. Unblocks VehicleComponent wheels, ScriptComponent
  properties, CameraFocusComponent targets, PlayerController `waterResponse`, PrefabInstance overrides.
  Done when: a guard test finds no saved component field that the inspector silently skips.
- **EDT-108** `P1` Asset reference fields: picker and drag and drop.
  An `@AssetRef(kind)` annotation (with skate-ecs, next to `@GameObjectRef`); the inspector shows a picker filtered
  by kind, accepts drops from the Asset Browser and flags missing files. Domain agents then annotate their fields
  (particle/UI texture, `configPath`, `meshRef`, `materialPath`, sound paths, …).
- **EDT-109** `P2` Add Component menu: translated names, categories and search on the translated name.
- **EDT-110** `P2` Copy / paste component values (enable the disabled "Copy component" item; paste as new or onto
  the same type), undoable.

### REN (skate-render)

- **REN-45** `P1` Post-processing panel. Design note first: where the values live (per scene on
  `EnvironmentComponent` or a new scene component, or per project) and how they combine with the quality preset.
- **REN-46** `P2` Sky / HDRI picker for `EnvironmentComponent.skyTexture`.
- **REN-47** `P2` Change the model of an existing RenderComponent (picker / drop), keeping material overrides
  where slot names match.
- **REN-48** `P2` `.skmat` file inspector: select a material in the Project window to edit it (a `FileInspector`).

### PHY (skate-physics)

- **PHY-30** `P2` Collision layers: named layers in Project Settings, a layer matrix, and layer / mask dropdowns
  on RigidBody3D instead of raw ints.
- **PHY-31** `P2` Collider gizmos: wireframe of the selected object's colliders and handles for size and offset.
- **PHY-32** `P2` Vehicle wheel editor (on EDT-107): add / remove wheels, viewport handles for wheel offsets.
- **PHY-33** `P3` Hull and mesh colliders: "Generate from mesh" and a vertex count summary instead of hidden lists.
- **PHY-34** `P3` Ragdoll profile: bone-to-body mapping, masses and limits as data with an inspector (today
  `RagdollBuilder` is Mixamo-only code).

### GPL (skate-gameplay)

- **GPL-33** `P2` Camera components in the editor: add CameraFocusComponent and FreeFlyCameraComponent to Add
  Component, a targets list for CameraFocus (EDT-107), and an object list instead of comma text for
  `CameraCycleComponent.cameraNames`.
- **GPL-34** `P2` PlayerController inspector: behaviour dropdown from the registered behaviours, `configPath`
  as an asset ref (EDT-108), water response section.
- **GPL-35** `P2` Control scheme tuning: trick and flick thresholds per scheme editable and saved per project
  (INP reviews the flick part).
- **GPL-36** `P2` `.item.json` inspector (part of or right after GPL-27).

### INP (skate-input)

- **INP-11** `P2` Project input actions: define actions and contexts in a project asset, edited in Key Bindings
  (add, rename, remove, default bindings), so a non-skate game does not need code for its actions.
  REWRITE-sized: design note first.
- **INP-12** `P2` Input action picker: `@InputActionRef` on action-id fields (`CameraCycleComponent.actionId` first)
  and a dropdown of known actions in the inspector. Depends on INP-11 for project actions.
- **INP-13** `P3` Rumble test in the Input Testing panel (pad, strength, duration, pattern).
- **INP-14** `P3` InputStateComponent: remove from Add Component, show it read-only (live values) while playing.

### ECS (skate-ecs)

- **ECS-23** `P2` Prefab overrides and prefab edit mode: list a PrefabInstance's overrides with Apply / Revert,
  and open a `.prefab` (double-click) in an isolated edit scene instead of the OS editor.
- **ECS-24** `P3` Hide code-only components from Add Component (NativeScriptComponent; same list as INP-14) or
  show a "set from code" note.

### SCR (skate-scripting)

- **SCR-02** `P2` Script parameters: show and edit `ScriptComponent.properties` from the script's declared
  parameters (on EDT-107).
- **SCR-03** `P3` Open `.glsl` files in the built-in Script Editor.

### GUI (skate-gameui)

- **GUI-21** `P2` Map components in the editor: UIMapComponent and UIMapMarkerComponent in the Create UI menu,
  `@GameObjectRef` on `target`, `openButton`, `closeButton`.
- **GUI-22** `P3` Font asset preview and size / atlas settings.

### AST / AUD (skate-assets, skate-audio)

- **AST-45** `P2` Texture import settings (sRGB, filtering, mipmaps, wrap, compression) in the inspector.
- **AST-46** `P2` Model import settings (scale, up axis, collision, material extraction), like EDT-66 for `.blend`.
- **AUD-03** `P3` Sound import settings (stream vs. load, default bus, loop points).
- **AUD-04** `P3` Water audio settings (splash and ambience sounds, volumes).

### NET (skate-online) — deferred

- **NET-02** `P3` Networking components and `NetConfig` in the editor, once multiplayer is user-facing.
