# QA-20: editor coverage audit

Audit only; no fix was made outside test code. Date: 2026-11-25, on master `e1bd7b53` (round 41a).
The lead adds the proposed tasks below to `GameEngine.md` (IDs are the next free number of each domain; renumber freely).

## Method

- **Components:** all 63 components registered in `Serializer.kt` (polymorphic `Component` module), taken from the serializer
  descriptors (so only *serialized* fields count; `@Transient` ones are out).
- **Inspector kinds** (`editor/imgui/components/Component.kt` dispatch):
  1. *dedicated*: one `fun X.imgui(engine)` per component (17 of them);
  2. *UI*: every `engine.ui.*` component, via `uiImgui` (labels `ui.inspector.<field>`);
  3. *generic*: `reflectedImgui` for everything else (labels `component.<Type>.<field>`).
- **Generic inspector capability** (what a "complete entry" can mean there): non-final `Int`/`Float` (plain drag, no range),
  `Boolean`, `String` (text, plus pickers only when the field carries `@AssetRef`/`@GameObjectRef`), `Vector2/3/4f`, non-final enums.
  Everything else is silently skipped: `Long`, `Double`, `List`, `Map`, arrays, nested objects, final scalars. A missing
  label key renders as `!!component.X.field!!`.
- **Guard test:** `ComponentInspectorCoverageGuardTest` (new) fails when a serialized field has no widget, no label or no
  tooltip. For dedicated inspectors the check is textual (the field name appears in the inspector source; some string key
  ends in `.<field>` and `.<field>.tooltip`), so it cannot prove the *right widget*, range or picker. Those points are
  marked "manual" below and need a human pass per component.
- **Allowlist:** `src/test/resources/architecture/component-inspector-allowlist.txt`, one `Type.field  # task` per known gap
  (116 entries). A stale entry also fails the test, so every fix must delete its line. The raw per-gap report is written to
  `build/reports/qa-20-inspector-gaps.txt` on each run.
- **Engine features:** engine packages and systems enumerated and searched in `editor/` code and `editor/strings` for a
  surface. "No surface found" is a grep heuristic: verify before filing.

### Cross-cutting generic-inspector gaps (owner `skate-ecs`, task ECS-29; EDT consulted for widgets)

1. No ranges/steps: every `Float`/`Int` is a free drag (`MImGui.dragFloat`); add `@Range(min,max,step)`-style metadata on component fields and honour it in the generic and UI inspectors.
2. Unsupported field types are skipped silently: `Long`, `Double`, `List`, `Map`, arrays, nested objects, final scalars. Add widgets, or a visible "not editable" row so a gap is never invisible.
3. Plain `String` fields without `@AssetRef`/`@GameObjectRef` are text boxes; audit which hold asset paths or object ids (e.g. `MeshCollider3D.meshRef`, `RenderComponent.materialPath`).
4. A missing label key shows `!!key!!` at runtime; `EditorStringKeysTest` cannot see keys built from `field.name`. The new guard now covers this for generic/UI components.
5. Runtime state saved to scene files (Animator, SkeletonComponent.pose, RagdollComponent.state, DirectionalLight matrix, InputState, NetState, DestructibleComponent.broken). Decide per field: `@Transient` or inspector-visible.
6. The dedicated-inspector check is textual; manual per-component pass for widget, range and asset-picker correctness is still needed (follow-up QA-21 once the allowlist is empty: golden screenshot or reflection-driven widget test).
