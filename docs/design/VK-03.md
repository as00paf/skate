# VK-03 — Geometry pass parity on Vulkan: report

Status: done (validation-layer run pending the LunarG SDK). Owner: skate-vulkan. Builds on VK-01 (frames, swapchain) and
VK-02 (resources, descriptors, `ShaderParams` → UBO).

## Result

The geometry pass needed **no backend or shared-code change** on top of VK-01 + VK-02. Every feature it draws matches
OpenGL. VK-03 adds the proof: `VulkanGeometryParityGpuTest` renders 18 views with each backend (geometry pass only,
1280x720), reads both back in GL row order and compares them.

**Tolerance** (asserted per view): mean channel difference ≤ 0.25/255, and ≥ 99.9% of pixels with no channel more than
2/255 off. The large maxima are each a handful of pixels (≤ 12 per frame) on triangle edges: coplanar pads over the
floor, and silhouettes where the rasterizers break coverage ties differently. Elsewhere the remaining differences are
1-LSB rounding in blending and filtering.

Skinned characters are posed by stepping only `AnimationSystem` with the scene briefly marked running. That avoids
cameras, physics or scripts, so both backends get the same deterministic pose. In edit mode they would stay in bind
pose, which makes skinning a no-op and would prove nothing.

## Notes

- `SkyboxRenderer` (cube-map skybox) is created but no pass draws it; the sky is the dome (procedural or HDRI). Its
  shader compiles on Vulkan (`EngineShadersVulkanTest`). If a pass starts drawing it, add a view here.
- Shadows are off in these views (the shadow pass is VK-04); the geometry pass then binds the far-depth dummy shadow
  maps.
- **Validation-sensitive spots** to watch in the SDK run:
  - the geometry pass samples images in their resting layouts (`SHADER_READ_ONLY`, `DEPTH_STENCIL_READ_ONLY` for
    shadow maps), so descriptor layouts must match;
  - uploads go through `core.oneShot` while a frame is recorded, so a mid-frame texture change runs before earlier
    recorded draws;
  - stride-0 dummy vertex bindings stand in for missing attributes (tangents, joints);
  - uniform ring offsets must be aligned to `minUniformBufferOffsetAlignment`;
  - sprite and sky pipelines use both-face culling and LEQUAL depth.
- OpenGL is unchanged (no main-source change in VK-03), so REN-22 timings cannot regress.
