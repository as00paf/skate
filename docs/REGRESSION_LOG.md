# Regression Log

Track every discovered regression here. Do not fix issues that are not logged.

## Status Legend

- `open` - identified, not started
- `in_progress` - actively being fixed
- `blocked` - cannot proceed; waiting dependency/decision
- `resolved` - fix implemented and verified
- `deferred` - intentionally postponed with rationale

## Severity Legend

- `P0` - startup/build/crash/data-loss blocker
- `P1` - core behavior broken, major workflow impact
- `P2` - incorrect behavior with workaround
- `P3` - low impact/cosmetic/non-critical
