## Executive Summary

This plan covers the implementation of a comprehensive Project Creation & Management System (A46.0.9) integrated with a complete Settings System Architectural Separation (A46.0.10). The system will provide a professional project workflow similar to Unity/Unreal Engine, with proper separation of engine, project, user, and hardware settings.

---

## Architecture Overview

### Settings Hierarchy:

```
┌─────────────────────────────────────────────────┐
│                 SettingsManager                  │
├─────────────────────────────────────────────────┤
│  EngineSettings (global, engine-wide)           │
│  ├── Editor settings (UI theme, layout)         │
│  ├── Build settings (default platform)          │
│  └── Auto-save settings                         │
├─────────────────────────────────────────────────┤
│  ProjectManager (per-project)                   │
│  ├── ProjectSettings                            │
│  │   ├── Project info (name, version, path)     │
│  │   ├── Scene settings (default scene)         │
│  │   └── Asset paths                            │
│  └── GameplaySettings                           │
│      ├── Physics settings                       │
│      └── Game-specific config                   │
├─────────────────────────────────────────────────┤
│  UserSettings (user preferences)                │
│  ├── UI preferences (theme, font size)          │
│  ├── Keybindings                                │
│  └── Workflow preferences                       │
├─────────────────────────────────────────────────┤
│  HardwareSettings (auto-detected + overrides)   │
│  ├── Display settings (resolution, fullscreen)  │
│  ├── Graphics settings (quality, MSAA)          │
│  └── Audio settings (volume, device)            │
└─────────────────────────────────────────────────┘
```

### Project File Structure:

```
MyProject/
├── MyProject.skateproject    # Project configuration file
├── Scenes/                    # Scene files
├── Assets/                    # Asset files
│   ├── Models/
│   ├── Textures/
│   ├── Sounds/
│   └── Animations/
├── Builds/                    # Build output
└── Settings/                  # Project-specific settings
```

// Settings Window with tabs
class SettingsWindow : IWindow, KoinComponent {
    private val settingsManager: SettingsManager by inject()
    private val projectManager: ProjectManager by inject()
    
    private var currentTab = SettingsTab.ENGINE
    private var hasUnsavedChanges = false
    
    enum class SettingsTab {
        ENGINE,    // Engine-wide settings
        PROJECT,   // Project-specific settings
        USER,      // User preferences
        HARDWARE   // Graphics, audio, input
    }
    
    override fun render() {
        if (ImGui.begin("Settings", isOpen, ImGuiWindowFlags.AlwaysAutoResize)) {
            // Tab bar
            if (ImGui.beginTabBar("##SettingsTabs")) {
                for (tab in SettingsTab.values()) {
                    val tabName = tab.name.lowercase().capitalize()
                    if (ImGui.beginTabItem(tabName)) {
                        renderTabContent(tab)
                        ImGui.endTabItem()
                    }
                }
                ImGui.endTabBar()
            }
            
            // Action buttons
            ImGui.separator()
            if (hasUnsavedChanges) {
                if (ImGui.button("Save Changes")) {
                    saveSettings()
                }
                ImGui.sameLine()
            }
            if (ImGui.button("Reset to Defaults")) {
                resetCurrentTabToDefaults()
            }
            ImGui.sameLine()
            if (ImGui.button("Close")) {
                isOpen = false
            }
            
            ImGui.end()
        }
    }
}
```

**Tab Content:**
- **Engine Tab**: Editor theme, auto-save, layout preferences
- **Project Tab**: Project name, version, default scene, asset paths
- **User Tab**: UI theme, font size, keybindings, workflow preferences
- **Hardware Tab**: Resolution, fullscreen, VSync, graphics quality, MSAA, audio volume

**Acceptance Criteria:**

// Boot sequence with project awareness
class BootManager @Inject constructor(
    private val projectManager: ProjectManager,
    private val settingsManager: SettingsManager,
    // ... other dependencies
) {
    suspend fun boot(engineState: EngineState) {
        // 1. Load engine settings
        settingsManager.loadEngineSettings()
        
        // 2. Load user settings
        settingsManager.loadUserSettings()
        
        // 3. Load hardware settings & apply
        settingsManager.loadHardwareSettings()
        applyHardwareSettings()
        
        // 4. Check for last opened project
        val lastProjectPath = settingsManager.user.lastOpenedProject
        if (lastProjectPath != null && File(lastProjectPath).exists()) {
            projectManager.openProject(File(lastProjectPath))
        }
        
        // 5. If no project loaded, show wizard on first frame
        if (projectManager.currentProject == null) {
            engineState.showProjectWizard = true
        }
        
        // 6. Continue with normal boot...
    }
}
```

## Risks and Mitigations

| Risk | Impact | Likelihood | Mitigation |
|------|--------|------------|------------|
| Settings migration from old format | High | Medium | Create migration utility, backup old settings |
| Project file corruption | High | Low | Validate on load, create backup on save |
| Boot sequence issues | High | Medium | Extensive logging, fallback to safe mode |
| DI circular dependencies | Medium | Low | Careful dependency graph design, test early |
| Wizard UI complexity | Medium | Medium | Keep wizard simple, iterate based on feedback |
| Settings window performance | Low | Medium | Lazy load tab content, cache settings |
