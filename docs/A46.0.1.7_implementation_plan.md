# Implementation Plan: A46.0.1.7 - Enhance Scene Hierarchy

## Objective
Enhance the Scene Hierarchy window to include visibility/lock toggles, a search bar, a "+" button for adding new entities, and a link button.

## Context
The Scene Hierarchy currently displays a list of GameObjects but lacks quick toggles and advanced search functionalities. This task will bring it closer to an IntelliJ-like or standard game engine standard by providing better navigation and direct manipulation controls.

## Target Agent
@software-engineer

## Actionable Steps

### 1. UI Layout Preparation
- Update the `HierarchyWindow` layout to include a top toolbar row (or integrated with ImGui headers).
- Ensure the main content uses ImGui Tables or calculated layout widths to properly align the hierarchy tree on the left and toggles on the right.

### 2. Search Bar Implementation
- Add an `ImGui.inputText` (or similar filter widget) at the top of the Hierarchy window for searching/filtering GameObjects by name.
- Implement filtering logic: when the search query is not empty, only display GameObjects whose name (or components) matches the query (case-insensitive). Keep the parent-child structure intact if a child matches.

### 3. "+" Button and Link Button
- Next to the search bar, add a "+" (Add) button.
- Clicking the "+" button should open a popup or directly create a new empty GameObject in the active scene and select it.
- Add a "Link" button (e.g., to sync selection with the viewport or auto-scroll to selected). Define its basic toggle state or behavior, matching the UI mockups/theme.

### 4. Visibility and Lock Toggles per GameObject
- Ensure `GameObject` has properties for `isVisible` and `isLocked`, or add them if they do not exist. (Alternatively, manage this state via editor-specific components or flags).
- **Visibility Toggle**: 
  - For each item in the hierarchy tree, add an eye icon (`fa-eye` / `fa-eye-slash`) aligned to the right.
  - Clicking it toggles the GameObject's visibility state. The Renderer needs to respect this flag.
- **Lock Toggle**:
  - Next to the visibility toggle, add a lock icon (`fa-lock` / `fa-unlock`).
  - Clicking it sets a locked state. Locked GameObjects should not be selectable or editable via the Scene Viewport.

### 5. UI/UX Polish
- Use appropriate FontAwesome icons (already available in `assets/fonts/`).
- Ensure the layout remains clean and the UI interactions (selecting an item vs clicking a toggle) do not conflict.
- Test the Hierarchy panel resizing to ensure the right-aligned elements stay positioned correctly.
