# Implementation Plan: A46.0.1.9 - Enhance Console Window

## Objective
Enhance the Console Window by adding search filtering and a "Clear" button, ensuring a clean and consistent UI layout that matches other revamped editor windows.

## Requirements
- Add a search function to filter log messages by content.
- Add a "Clear" button to empty the console log (both Engine and Editor logs).
- Implement a full-width toolbar for search and clear actions.
- Use `StringManager` for localized tooltips and labels.
- Ensure the layout is professional and matches the "Islands Dark" theme.

## Proposed Changes

### 1. Localization (`src/main/resources/values/strings.properties`)
Add the following keys:
- `tooltip.search_console=Filter console messages by content`
- `tooltip.clear_console=Clear all console logs`
- `lbl.clear=Clear`

### 2. Logger Service (`src/main/kotlin/com/pafoid/skate/editor/systems/LoggerService.kt`)
Add methods to clear the logs:
```kotlin
fun clearEngineLogs() {
    engineLogs.clear()
}

fun clearEditorLogs() {
    editorLogs.clear()
}

fun clearAllLogs() {
    clearEngineLogs()
    clearEditorLogs()
}
```

### 3. Console Window (`src/main/kotlin/com/pafoid/skate/editor/windows/ConsoleWindow.kt`)
- Add a private field `private val searchText = ImString(256)`.
- Implement `renderToolbar()`:
  - Calculate available width.
  - Render a full-width toolbar above the tabs.
  - Include an `inputTextWithHint` for search with `Icons.SEARCH`.
  - Include a "Clear" button with `Icons.TRASH`.
  - Add tooltips to both elements.
- Update `renderLogList(logs: Iterable<LogEntry>)`:
  - Filter `logs` using `searchText.get()` before rendering.
  - The filter should be case-insensitive.
- Update `imgui(pOpen: ImBoolean?)`:
  - Call `renderToolbar()` before `beginTabBar()`.
