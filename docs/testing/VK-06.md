# VK-06 — Runtime UI, particles and debug lines on Vulkan: how to test

Windows with a Vulkan driver, a branch that contains VK-05 (`agents/vulkan`, the unflipped-target convention).
Commands run from the repository root in `cmd`.

1. **Opt in.** `set SKATE_RHI=vulkan`. Until the LunarG SDK is installed, also `set SKATE_VK_VALIDATION=0`.
2. **Run the parity test.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanOverlayParityGpuTest` -> PASSED
   (about 30 s). It renders 10 views with OpenGL, then with Vulkan.
3. **Read the report.** In `build\vk06\report.txt`, no line has `FAIL`. The UI and particle views have mean 0.000.
   Debug views have at least 99.8% of pixels within 2/255 (see `docs/design/VK-06.md` for why `debug-grid` is the
   lowest).
4. **Look at the frames.** Open `ui-pause-menu-vulkan.png` and `ui-pause-menu-gl.png`: the same dimmed scene and
   pause panel with crisp text. `particles-area-vulkan.png` shows fire, smoke, sparks and the fountain.
   `debug-physics-vulkan.png` shows green collider wireframes. The `*-diff.png` images are black apart from a few
   pixels along the origin axes.
5. **Check the earlier Vulkan tests.** `gradlew.bat :test --tests "com.pafoid.skate.engine.render.rhi.vulkan.*"` ->
   all pass, including VK-03's geometry parity.
6. **Check OpenGL is unchanged.** Unset `SKATE_RHI`, run `gradlew.bat run`, open the Feature Showcase and press
   Play. The legend, the pause menu (Esc), particles and the editor grid look and perform as before.
