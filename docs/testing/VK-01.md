# VK-01 — Windowed Vulkan runtime: how to test

Windows, a GPU with a Vulkan driver. All commands run from the repository root in `cmd`.

1. **Install the validation layer (once).** Either install the LunarG Vulkan SDK, or download
   `Validation_Layers_Windows_64.zip` from the `nightly` release of
   [KhronosGroup/Vulkan-ValidationLayers](https://github.com/KhronosGroup/Vulkan-ValidationLayers/releases/tag/nightly)
   and unzip it to `build\vk-layers` (it holds `VkLayer_khronos_validation.dll` and `.json`).
2. **Point the loader at it and opt in to Vulkan.** You can skip the first line if you installed the SDK.
   ```
   set VK_ADD_LAYER_PATH=%CD%\build\vk-layers
   set SKATE_RHI=vulkan
   ```
3. **Run the presenting harness.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanPresentGpuTest`
   A small window opens several times for a few seconds: solid clears, a resize to three sizes, a minimize and
   restore, a vsync switch, then the MainScene geometry pass at 1280x720 and 960x540. All 5 tests pass. Any
   validation error fails the test and is printed by the `skate.rhi.vulkan` logger.
   If the layer is missing, the tests fail with "VK_LAYER_KHRONOS_validation is not installed". To run them
   without the layer anyway, `set SKATE_VK_VALIDATION=0`.
4. **Check parity did not regress.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanGeometryPassGpuTest`, then open
   `build\ren13\report.txt`: max channel diff ≤ 1, 100% of pixels within 2/255 (REN-13 numbers).
5. **Check the unit tests run without a GPU.**
   `set CI=true` then `gradlew.bat :test --tests "com.pafoid.skate.engine.render.rhi.vulkan.*"`. `FrameRingTest` and
   `SwapchainPolicyTest` run. The two GPU tests are skipped.
6. **Check OpenGL is unchanged.** Unset `SKATE_RHI`, start the editor and press Play on the default project: it looks
   and performs as before. VK-01 touched no OpenGL or shared RHI code.
