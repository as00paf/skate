# QA-12 manual test: isolation guard for shadow, particle and camera logic

QA-12 adds only a unit-test guard. It has no user-visible feature, so the Feature Showcase is unchanged. The steps below check that the guarded code still works in a real scene loaded from disk.

1. Run `.\gradlew.bat test --tests "com.pafoid.skate.architecture.PureLogicIsolationGuardTest"`. All 4 tests pass.
2. Start the editor and create a **new project**. The default scenes, including Feature Showcase, are generated and saved to disk.
3. Close the editor, reopen it and open the new project's **Feature Showcase** scene from disk.
4. In the viewport, confirm that the directional light casts cascaded shadows and that spot and point lights cast local shadows (shadow maths).
5. Find the particle emitter demo and press **Play**. Particles spawn, move and despawn without errors in the console (ParticleSimulator/ParticlePool).
6. Stop play. Orbit, pan and zoom the editor camera; the motion is smooth (CameraMotion). Click objects to select them: the right object is picked at the viewport edges too (ViewportPointer mapping).
7. Optional negative check: add `val probe = org.lwjgl.opengl.GL11.GL_TRUE` to a new file in `engine/render/shadow/`. Re-run step 1: `PureLogic_ShadowParticleAndCameraMathsStayPlatformFree` fails. Delete the file.
