# QA-10 manual verification steps

QA-10 delivers unit tests and an architecture guard only. There is no editor UI, menu or project to create; everything is verified from the command line on Windows (natives are Windows-only). From WSL, prefix commands with `cmd.exe /c` and quote them as shown.

## Starting from a clean state

1. Open a terminal in the repository root (the `agents/qa` worktree, or master once merged).
2. Run `git status --short`. Expected: no output (clean tree).
3. Confirm the commit is present: `git log --oneline -5`. Expected: a line `QA-10: component registration guard and ReverbZone serialization test`.
4. Clean old results: `.\gradlew.bat clean` (WSL: `cmd.exe /c "gradlew.bat clean --console=plain"`). Expected: `BUILD SUCCESSFUL`.

## Run the new tests

5. Run the serialization test:
   `.\gradlew.bat test --tests "com.pafoid.skate.engine.ecs.components.ReverbZoneSerializationTest"`
   Expected: `BUILD SUCCESSFUL`. A "No tests found" message from the JaCoCo finalizer task can be ignored. Open `build/test-results/test/TEST-com.pafoid.skate.engine.ecs.components.ReverbZoneSerializationTest.xml`: `tests="1" skipped="0" failures="0"`.
6. Run the guard:
   `.\gradlew.bat test --tests "com.pafoid.skate.architecture.ComponentRegistrationGuardTest"`
   Expected: `BUILD SUCCESSFUL`; the result XML shows `tests="1" failures="0"`.

## Prove the guard catches a regression

7. In `src/main/kotlin/com/pafoid/skate/engine/assets/serialization/Serializer.kt`, delete the line `subclass(ReverbZone::class)`.
8. Re-run step 6. Expected: `FAILED` with the message `Components missing from Serializer polymorphic module: [ReverbZone]`.
9. Re-run step 5. Expected: FAILED (the polymorphic encode/decode of `ReverbZone` throws a serialization error).
10. Restore the line: `git checkout -- src/main/kotlin/com/pafoid/skate/engine/assets/serialization/Serializer.kt`, then `git status --short`. Expected: no output.

## Full suite

11. Run `.\gradlew.bat test`. Expected: `BUILD SUCCESSFUL`, 0 failed, 1 skipped (the `@Disabled` CameraTest lerp case, BUG-014).
12. Optional: `.\gradlew.bat build test jacocoTestReport` (the CI command). Expected: `BUILD SUCCESSFUL`; the report is at `build/reports/jacoco/test/html/index.html`.

## Coverage audit (round 7)

13. Confirm these existing tests pass: `EditorDialogTest`, `PrefabsGeneratorTest`, `PluralRulesTest`, `PrefabServiceTest`, `SdfFontTest`, `MountTest`, `EffectsTest` (reverb zone resolver). In `build/test-results/test/` each corresponding `TEST-*.xml` must show `failures="0"`.
