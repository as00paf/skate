# VK-03 — Geometry pass parity on Vulkan: how to test

Windows, a GPU with a Vulkan driver. All commands run from the repository root in `cmd`.

1. **Opt in to Vulkan.** `set SKATE_RHI=vulkan`. Until the LunarG Vulkan SDK is installed, also run
   `set SKATE_VK_VALIDATION=0`. Once the SDK is installed, leave validation on so any error fails the test.
2. **Run the parity suite.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanGeometryParityGpuTest`
   It takes about a minute and passes. It renders 18 views with OpenGL, then with Vulkan.
3. **Read the report.** Open `build\vk03\report.txt`. Every view has a mean of 0.25 or less, at least 99.9% of pixels
   within 2/255, and no `FAIL` marker.
4. **Look at the frames.** In `build\vk03`, open `main-skater-gl.png` and `main-skater-vulkan.png`. The skater stands
   in an idle pose, not a T-pose, and the two images look the same. In `showcase-alpha-mask-vulkan.png`, the
   textured cube is gone and the blue cube is solid. `showcase-inside-double-sided-vulkan.png` shows grey walls, while
   `showcase-inside-culled-vulkan.png` shows sky. The `*-diff.png` images are black except for a few isolated pixels.
5. **Check the earlier Vulkan tests still pass.**
   `gradlew.bat :test --tests "com.pafoid.skate.engine.render.rhi.vulkan.*"`. This also runs the REN-13 comparison
   and the VK-01 presenting harness (a window opens briefly).
6. **Check OpenGL is unchanged.** Unset `SKATE_RHI`, start the editor and press Play on the default project: it looks
   and performs as before. VK-03 changed no engine code.
