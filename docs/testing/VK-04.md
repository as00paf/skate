# VK-04 test steps: shadows on Vulkan

Cascaded sun shadows and spot/point shadow maps on the Vulkan backend (exported games). OpenGL is unchanged.

1. `.\gradlew.bat run`, create a NEW project, open `FeatureShowcase`, focus the Shadows area → shadows look as before
   (OpenGL). In Settings, switch shadow quality Low → Medium → High → shadows sharpen, nothing else changes.
2. In a `cmd` shell: `set SKATE_RHI=vulkan` and `set SKATE_VK_VALIDATION=0` (use `1` once the LunarG SDK is installed),
   then `.\gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanShadowParityGpuTest` → passes.
3. Open `build/vk04/report.txt` → every view (Shadows area, spot close-up, MainScene sun) at Low/Medium/High and the
   "moved" view are within tolerance; the cache line says the static frame is identical and Vulkan skipped as many
   shadow layers as OpenGL.
4. Compare `build/vk04/showcase-shadows-high-gl.png` with `...-vulkan.png` → the same shadows (cube, pillar, spot
   sphere, point light, group); `...-diff.png` is black.
5. Export the project with the Vulkan backend (Project Settings → Graphics backend: Vulkan), run the game and walk to
   the Shadows area → the same shadows as the OpenGL game; moving casters update their shadows.
