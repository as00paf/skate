# EDT-52G — Hamburger menu, Settings submenu, About

1. Open the ☰ menu: the submenus are, in order, File, Edit, View, Play, Settings, Tools, Help. Every item shows an icon, its shortcut where it has one, and a tooltip on hover.
2. With no project open, File › Save Project, Save Project As…, Close Project and Export… are greyed out. Open a project: they become available. Recent ▸ lists other projects; hover one to see its path.
3. Select a GameObject: Edit › Duplicate copies it and Edit › Delete removes it (Ctrl+Z restores it). With nothing selected, Cut, Copy, Duplicate and Delete are greyed out. Edit › Search Anywhere… opens search.
4. Play › Play / Pause starts Play (the item shows a tick), again pauses it; Stop and Reset are greyed out in Edit mode and work during Play, like the viewport toolbar.
5. Settings › Language ▸ shows English / Français with the current one ticked; pick Français and the menu text switches without the menu closing on a combo. Units ▸ does the same for Metric / Imperial. There is no overlay size slider any more (it is in Editor Settings).
6. Settings › Show gamepad overlay toggles the overlay. Show tooltips toggles its tick (placeholder until EDT-57; tooltips still show). Editor Settings…, Project Settings… and Key Bindings… open their windows.
7. Tools › Test Input… (or Ctrl+Shift+I) opens Input Testing; Tools › Shell opens the Shell. The old Input menu is gone. Help › Keyboard Shortcuts opens Key Bindings; Help › About Skate shows a modal with the version, closed by Close, Enter or Esc.
8. Hover the title bar's Maximize/Restore button: a tooltip says Maximize or Restore to match the window state. The gear popup's Project Settings uses the sliders icon.
