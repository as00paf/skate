# QA-17 manual test steps

QA-17 removes every build warning and makes new ones fail the build. Two editor code paths changed along the way (the enum combo in the Inspector and the UI rect gizmo click), so they get a quick smoke test.

Run from the repository root in Windows `cmd`/PowerShell (from WSL, prefix with `cmd.exe /c`).

1. `.\gradlew.bat clean build --warning-mode=fail`. It succeeds, and the log has no `w:` lines, no `OpenJDK ... VM warning` and no "Deprecated Gradle features".
2. Add `@Deprecated("x") fun a() = 1; fun b() = a()` to any main Kotlin file and run `.\gradlew.bat compileKotlin`. It fails with `warnings found and -Werror specified`. Revert the file.
3. Start the editor (`.\gradlew.bat run`), select an object with an enum field (e.g. a Light's type or a RigidBody's body type), change it in the Inspector combo, then undo it. The value and the undo both work.
4. Open a scene with a UI canvas, select a UI element, then drag one of its rect handles in the viewport. It resizes, and undo restores it. Click another UI element: the selection moves to it.
5. Play a scene with a TypeScript script attached. It still runs, and file I/O stays blocked as before.
