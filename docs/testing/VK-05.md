# VK-05 — Post-processing on Vulkan: how to test

Windows, a GPU with a Vulkan driver. All commands run from the repository root in `cmd`.

1. **Opt in to Vulkan.** `set SKATE_RHI=vulkan`. Until the LunarG Vulkan SDK is installed, also run
   `set SKATE_VK_VALIDATION=0`.
2. **Run the post-processing parity suite.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanPostProcessParityGpuTest`
   It passes. Open `build\vk05\report.txt`: there are 11 views and none is marked `FAIL`.
3. **Look at the effects.** In `build\vk05`, compare `main-tonemap-gl.png` with `main-tonemap-vulkan.png`, then the
   same for `main-ssao` and `main-all`. Each pair looks the same and upright, with the sky at the top. In
   `main-ssao-*.png`, objects have dark contact halos.
4. **Check the presented window is upright.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanPresentGpuTest`. A window opens briefly
   and all 5 tests pass. The last test presents geometry with post-processing and checks the sky is at the top.
5. **Check nothing earlier regressed.**
   `gradlew.bat :test --tests "com.pafoid.skate.engine.render.rhi.vulkan.*" --tests com.pafoid.skate.game.GameVulkanStartGpuTest`
   All tests pass, and `build\vk03\report.txt` (geometry parity) has no `FAIL`.
6. **Check OpenGL is unchanged.** Unset `SKATE_RHI`, start the editor and press Play on the default project. Toggle
   post effects in the render settings: they look and perform as before. VK-05 changed only Vulkan backend code.
