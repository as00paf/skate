# VK-10 — Terrain splat shading and instanced scatter on Vulkan: how to test

Windows with a Vulkan driver, a branch that contains REN-36 tasks 5–7 (round 36) and VK-10 (`agents/vulkan`).
Commands run from the repository root in `cmd`.

## What was checked

No backend change was needed. The paths REN-36 tasks 5–7 added render on Vulkan as they are:

- **Splat shading.** `terrain.glsl` samples five `sampler2DArray`s (splat weights 0–3 and 4–7, layer albedo, normal,
  ORM; units 0–4) through `D2_ARRAY` image views; the per-chunk stream at location 1 is a `vec4`; `uBiomeColor0..7` and
  the layer tiling/triplanar `vec4`s land in the `Params` block.
- **Instanced scatter.** Scatter items draw through the INSTANCED mesh shader (instance stream at locations 10–13) and,
  with the shadow pass on, through the INSTANCED shadow pipeline as terrain shadow casters.

## Steps

1. **Opt in.** `set SKATE_RHI=vulkan`. Until the LunarG SDK is installed, also `set SKATE_VK_VALIDATION=0` (VK-07).
2. **Run the parity test.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanTerrainSplatScatterParityGpuTest` -> PASSED
   (about 30 s). It renders 4 views of the showcase island (`TerrainComponent.showcaseIsland()`) behind MainScene with
   OpenGL, then with Vulkan.
3. **Read the report.** In `build\vk10\report.txt`, no line has `FAIL`. Results on the reference machine (2026-11-17),
   VK-03 tolerance (mean ≤ 0.25/255, 99.9% within 2/255):

   | View | What it draws | Mean diff | Within 2/255 |
   |---|---|---|---|
   | island | splat-shaded island (beach, grass, rock layers); picking pass ran the terrain and scatter PICKING variants | 0.000 | 100.000% |
   | island-scatter | grass and rock slopes with scatter items (INSTANCED mesh shader) | 0.000 | 100.000% |
   | island-scatter-shadows | same, with the shadow pass: terrain DEPTH_ONLY and the INSTANCED shadow pipeline | 0.000 | 99.998% |
   | island-biomes | biome debug view (`uBiomeColor0..7`) | 0.000 | 100.000% |

   The test also asserts the scatter drew the same instances on both backends (7 in the last island-scatter frame).
4. **Look at the frames.** `island-biomes-vulkan.png` shows the biome regions in flat colours (beach, grass, rock);
   `island-scatter-shadows-vulkan.png` shows the scatter rocks' shadows on the slope. The `*-diff.png` images are black.

## Notes

- The test pins the project seed (`engine.random.reseed`), as in VK-09: each harness run otherwise builds other heights,
  splat weights and scatter.
- The shader compile check (`EngineShadersVulkanTest`) already covers `terrain.glsl` and its variants, and the INSTANCED
  shadow and picking variants (VK-09).
- Zero validation messages stays unproven until VK-07 (LunarG SDK).
