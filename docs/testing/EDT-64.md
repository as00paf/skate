# EDT-64 — EDT-52 follow-ups

1. Delete (or rename) your `imgui.ini` in `%APPDATA%\Skate` so ImGui forgets window positions, then start the editor.
2. Open **Editor Settings** from the gear. It opens **centred** on the editor window. Move it, close it and reopen it: it reopens where you left it.
3. Do the same with **Project Settings**, **Key Bindings** and **File > Export…**: each opens centred the first time.
4. In Editor Settings and Project Settings, the two panes end right above the footer (Cancel · Apply · OK) without a scrollbar on the dialog, as before.
5. Open **View > Windows**: there is no **Input** or **Settings** group any more; Key Bindings, Editor Settings and Project Settings are only reachable from the gear / Settings menu.
6. Close the project and open Project Settings: the "No project open" panel shows, with its New/Open Project buttons, and fits above the lone **Close**.
