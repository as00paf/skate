# QA-14 manual test: project lifecycle end to end

The automated version is `ProjectLifecycleEndToEndTest` (`src/test/kotlin/com/pafoid/skate/editor/systems/`). **When a workflow changes** (project or scene files, paths, settings, export, game startup), add the human's new step there, through the real managers and disk. Don't write a narrower test that skips them.

1. Run `.\gradlew.bat test --tests "com.pafoid.skate.editor.systems.ProjectLifecycleEndToEndTest"`. Steps 1–7 pass. Step 8 fails until BUG-021 is fixed.
2. Start the editor and choose **New Project**. Move a rail in `MainScene`, save the scene, then save the project. The console shows no ERROR, except the `metal.png` texture error until BUG-020 is fixed.
3. **File > Close Project**, then **File > Recent Projects > (the project)**. It opens with your edit.
4. Quit and restart the editor. The last project opens automatically.
5. Quit. Move the project folder somewhere else, start the editor and open the moved `.skateproject`. Scenes, textures and sounds load. The project's settings (Project Settings) are unchanged.
6. Switch to the `FeatureShowcase` tab and press **Play**: boxes fall, the character walks, music plays. Press **Stop**: everything returns to its start and the sound stops.
7. **File > Export…**: choose Pack only and an output folder, then export. The wizard shows success.
8. Run the exported game (Windows target). `MainScene` loads, and the skater animates once BUG-021 is fixed.
