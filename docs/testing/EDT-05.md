# EDT-05: Tooltips everywhere

1. Start the editor and create a **new project**. Hover each item in **File**, **Edit**, **View** and **Settings**,
   and the hamburger, minimize and close buttons: each shows a one-line explanation.
2. Hover every viewport toolbar button (select/move/rotate/scale, local/world, measure, play, reset, physics debug,
   screenshot), then right-click the viewport and hover the Create menu entries (3D objects, lights, prefabs).
3. Select the skateboard. In **Properties**, hover component fields (RigidBody3D mass, Transform, Render material
   rows such as Metallic) and the remove-component button. Select a UI element in the FeatureShowcase and hover
   its fields (anchors, pivot, text size).
4. Hover the round-16 windows' controls: **Shell** (Run, Cancel, Clear, presets), **File > Export** (targets,
   Browse, Start), the **Audio Inspector** mixer (volume, mute, low-pass), the Animator inspector (Play/Pause,
   Mask), and **Editor Settings > Interface > Theme**.
5. Switch to **French** (Settings > Language): the same tooltips are in French. Controls whose action is not built
   yet (e.g. Reimport, Import Scene) say "Pas encore disponible."
6. Edit > now lists a single **Cut** (the duplicate entry with the paste icon is gone).
