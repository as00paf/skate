## Manual (editor)
1. Settings > Editor Settings > General: set "Default projects folder" to an existing folder, OK. File > New Project. Expected: Location starts with that folder; clearing the setting restores Documents/Skate Projects.
2. Create a project from the Skate Game template, open Project Settings. Game: change Target FPS (preset, then Custom with a value) and the splash (Change, then Default). Physics: change Physics backend. Expected: each change applies, can be undone, and persists after save and reopen.
3. Set Physics backend to Simple, save, close and reopen the project, then Play. Expected: the project's backend is used (Jolt shows the fallback warning when its native library is missing).
