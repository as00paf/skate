# VK-09 — Instancing and terrain on Vulkan: how to test

Windows with a Vulkan driver, a branch that contains REN-36 tasks 2–4 (round 35) and VK-09 (`agents/vulkan`).
Commands run from the repository root in `cmd`.

## What was checked

No backend change was needed. The paths REN-36 added already translate and render on Vulkan:

- **Instance stream.** `VertexLayouts.INSTANCE_TRANSFORM` (locations 10–13, per-instance binding after the mesh
  bindings) maps to `VK_VERTEX_INPUT_RATE_INSTANCE`; `drawIndexed(..., instances)` becomes `vkCmdDrawIndexed` with the
  instance count. The DYNAMIC instance buffer goes through the per-frame vertex ring like particles.
- **Terrain.** `VertexLayouts.TERRAIN` has two bindings (shared grid, per-chunk stream); `terrain.glsl`'s
  `#if defined(DEPTH_ONLY)` / `#elif defined(PICKING)` / `#else` fragment branches each put their output on location 0
  (the VK-08 translator fix), and DEPTH_ONLY has none (shadow layers).

## Steps

1. **Opt in.** `set SKATE_RHI=vulkan`. Until the LunarG SDK is installed, also `set SKATE_VK_VALIDATION=0` (VK-07).
2. **Run the parity test.**
   `gradlew.bat :test --tests com.pafoid.skate.engine.render.rhi.vulkan.VulkanInstancingTerrainParityGpuTest` -> PASSED
   (about 45 s). It renders 3 views with OpenGL, then with Vulkan.
3. **Read the report.** In `build\vk09\report.txt`, no line has `FAIL`. Results on the reference machine (2026-11-17),
   VK-03 tolerance (mean ≤ 0.25/255, 99.9% within 2/255):

   | View | What it draws | Mean diff | Within 2/255 |
   |---|---|---|---|
   | terrain | MOUNTAINS hills behind MainScene, TerrainPass; picking pass ran the PICKING variant | 0.000 | 100.000% |
   | terrain-shadows | same terrain with the shadow pass: DEPTH_ONLY caster into the sun cascades | 0.000 | 99.999% |
   | instanced-cubes | 36 rotated, scaled cubes in one `ModelRenderer.drawInstanced` call (INSTANCED mesh shader) | 0.001 | 100.000% |

4. **Look at the frames.** `terrain-shadows-vulkan.png` shows the peaks shadowing the slopes; `instanced-cubes-vulkan.png`
   shows the orange cube grid around the skater. The `*-diff.png` images are black.
5. **Shader coverage without a GPU.** `EngineShadersVulkanTest` also compiles the INSTANCED variants (mesh, mesh + WIND,
   shadow, picking) and terrain's PICKING and DEPTH_ONLY variants to SPIR-V.

## Notes

- The test pins the project seed (`engine.random.reseed`): each harness run creates a project with a new random seed,
  so without it GL and Vulkan generate different heights (a GL-vs-GL run differs as much).
- No engine pass draws instanced meshes yet (vegetation, REN-29 task 14b). The test adds a small pass that draws one
  batch; the instanced shadow and picking variants are compile-checked only until then.
- Zero validation messages stays unproven until VK-07 (LunarG SDK).
