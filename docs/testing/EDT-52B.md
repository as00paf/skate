# EDT-52B — Scene windows follow the window standard

1. **Scene Hierarchy:** the tab shows a sitemap icon. The search box, **+** and link buttons sit on one header line with a **?** at the right. Click **?**: a help popover explains the window, with buttons that open Properties and Game Viewport.
2. Right-click the **Hierarchy tab**: Help, Reset position and Close window. Drag the Hierarchy out to float, then choose **Reset position**: it docks back on the left.
3. In the Hierarchy, right-click **empty space** below the objects: Create ▸ (the same items as the viewport menu, including UI ▸), Paste, Expand all, Collapse all and Rename scene. Create ▸ Light ▸ Point adds a top-level light.
4. Right-click an **object** in the Hierarchy: create items first, then Rename / Duplicate / Focus / Lock / Visible, then Copy / Cut / Paste as child, then Expand / Collapse, with **Delete** at the very bottom.
5. **Properties:** the tab shows a sliders icon and a header line with **?**. Right-click empty space under the components: **Add component…** opens the component list. Right-click a component header: Reset to default, Copy (grayed out), then **Remove component** last.
6. Click a component's trash button, or Remove component from its menu: one centred modal asks to confirm, naming the component and the object, with **Cancel** and a red **Remove Component** on the right. Esc cancels; Enter removes; Ctrl+Z brings the component back.
7. **Game Viewport:** a small **?** is the last button of the viewport toolbar and opens the viewport's help. Right-click in the viewport with nothing selected: Focus, Duplicate and Delete are grayed out (not missing), Paste is there, and Delete is last.
8. Edit a scene so it is unsaved (tab shows a dot), then close its tab: a centred modal asks to confirm, with **Cancel** and a red **Close without saving**. Cancel keeps it open; Close without saving closes it.
