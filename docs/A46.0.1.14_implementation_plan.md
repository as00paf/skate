# A46.0.1.14: "Search Everywhere" Global Search - Implementation Plan

## Executive Summary

Implement a unified global search feature inspired by Unity's "Quick Search" and VS Code's "Ctrl+P" that allows users to search across all editor resources (GameObjects, assets, components, actions) from a single searchable overlay.

**Priority:** High  
**Estimated Effort:** 16-20 hours  
**Complexity:** Medium-High  
**Dependencies:** None (standalone feature)

---

## Current State Analysis

### Existing Search Capabilities

| Window | Search Scope | Limitations |
|--------|-------------|-------------|
| **SceneHierarchyWindow** | GameObject names only | No component/tag search, no keyboard shortcut |
| **AssetBrowserWindow** | Asset filenames | Per-tab only, no metadata search |
| **ConsoleWindow** | Log messages | No regex, no highlighting |
| **PropertiesWindow** | Component names | Resets on selection change |

### 2. Data Flow

```
User presses Ctrl+P
    ↓
SearchEverywhereWindow opens (overlay)
    ↓
User types query
    ↓
SearchEngine queries all SearchProviders
    ↓
Results aggregated and scored
    ↓
Results displayed with categories
    ↓
User selects result (Enter/Click)
    ↓
Navigate to selected resource
    ↓
Add to SearchHistory
    ↓
Close overlay
```

### 3. Search Providers

#### GameObjectSearchProvider
- **Searches:** GameObject names, tags, layers
- **Data Source:** SceneManager.currentScene.gameObjectManager
- **Result Action:** Select GameObject in hierarchy, focus in viewport

#### AssetSearchProvider
- **Searches:** Asset filenames, types, paths
- **Data Source:** ResourceManager (textures, models, animations, sounds, prefabs)
- **Result Action:** Open AssetBrowser, highlight asset

#### ComponentSearchProvider
- **Searches:** Component type names, property names
- **Data Source:** GameObject components (selected or all)
- **Result Action:** Select GameObject, expand component in PropertiesWindow

#### ActionSearchProvider
- **Searches:** Editor actions, menu items, commands
- **Data Source:** Hardcoded action list (future: reflection-based)
- **Result Action:** Execute action (e.g., "Create Empty", "Save Scene")

class GameObjectSearchProvider(
    private val sceneManager: SceneManager
) : SearchProvider {
    override val category = SearchCategory.GAMEOBJECT
    
    override suspend fun search(query: String): List<SearchResult> {
        val scene = sceneManager.currentScene ?: return emptyList()
        return scene.gameObjectManager.gameObjects
            .filter { it.name.contains(query, ignoreCase = true) }
            .map { go ->
                SearchResult(
                    id = "go_${go.uid}",
                    displayName = go.name,
                    category = SearchCategory.GAMEOBJECT,
                    subcategory = "GameObject",
                    description = "UID: ${go.uid}",
                    relevanceScore = calculateRelevance(go.name, query),
                    metadata = mapOf("uid" to go.uid)
                )
            }
    }
    
    override fun navigate(result: SearchResult) {
        val uid = result.metadata["uid"] as Int
        val scene = sceneManager.currentScene
        val gameObject = scene?.gameObjectManager?.getGameObject(uid)
        gameObject?.let {
            scene.setSelectedGameObject(it)
        }
    }
}

```kotlin
class SearchEverywhereWindow(
    private val searchEngine: SearchEngine,
    private val stringManager: StringManager
) : IWindow {
    private var isOpen = false
    private val searchQuery = ImString(256)
    private var selectedResultIndex = 0
    private var currentResults: Map<SearchCategory, List<SearchResult>> = emptyMap()
    private var isSearching = false
    
    override fun imgui(pOpen: ImBoolean?) {
        if (!isOpen) return
        
        // Modal overlay
        val viewport = ImGui.getMainViewport()
        ImGui.setNextWindowPos(viewport.workCenterX, viewport.workCenterY, ImGuiCond.Always, 0.5f, 0.5f)
        ImGui.setNextWindowSize(600f, 500f)
        
        ImGui.begin("Search Everywhere", ImGuiWindowFlags.Modal or ImGuiWindowFlags.NoResize)
        
        // Search input
        ImGui.pushItemWidth(-1f)
        val enterPressed = ImGui.inputTextWithHint(
            "##SearchEverywhere",
            "Search GameObjects, Assets, Actions...",
            searchQuery
        )
        
        // Real-time search (debounced)
        if (!isSearching && searchQuery.get().isNotEmpty()) {
            JobSystem.runAsync {
                isSearching = true
                currentResults = searchEngine.search(searchQuery.get())
                isSearching = false
            }
        }
        
        // Results display
        ImGui.separator()
        ImGui.beginChild("SearchResults", 0f, 400f)
        renderResults()
        ImGui.endChild()
        
        // Footer with shortcuts
        ImGui.separator()
        ImGui.textColored(0.5f, 0.5f, 0.5f, 1f, "↑↓ Navigate  Enter Open  Esc Close")
        
        ImGui.end()
    }
    
    private fun renderResults() {
        var index = 0
        currentResults.forEach { (category, results) ->
            if (results.isEmpty()) return@forEach
            
            // Category header
            ImGui.textColored(categoryColor(category), "${category.displayName} (${results.size})")
            
            // Results
            results.forEach { result ->
                val isSelected = (index == selectedResultIndex)
                if (isSelected) {
                    ImGui.pushStyleColor(ImGuiCol.Header, 0.2f, 0.4f, 0.6f, 1f)
                }
                
                if (ImGui.selectable("${result.icon} ${result.displayName}", isSelected)) {
                    searchEngine.navigate(result)
                    isOpen = false
                }
                
                if (isSelected) ImGui.popStyleColor()
                index++
            }
        }
    }
}
```

## Performance Considerations

### 1. Debouncing
- Delay search by 150-200ms after last keystroke
- Prevents excessive searching while typing

### 2. Async Search
- Run search on background thread (JobSystem.runAsync)
- Update UI on main thread (JobSystem.runOnMain)

### 3. Caching
- Cache asset file lists (don't scan disk on every search)
- Cache GameObject lists (update only on scene changes)

### 4. Result Limiting
- Max 50 results per category
- Prevents UI slowdown with large result sets
