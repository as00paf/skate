# Implementation Plan - A46.0.1.8: Enhance Asset Browser Window

## Goal
Improve the Asset Browser Window's usability by adding tooltips, optimizing the layout for full-width search, implementing dynamic grid columns, and refactoring the Sounds tab with better controls and information.

## Proposed Changes

### 1. Tooltips & Localization (@software-engineer)
- Add the following keys to `assets/strings.properties`:
  - `tooltip.refresh_assets=Refresh asset list from disk`
  - `tooltip.search_assets=Filter assets by name`
  - `tooltip.play_sound=Play audio preview`
  - `tooltip.stop_sound=Stop audio preview`
- Update `AssetBrowserTab.kt` to show tooltips for the search bar and refresh button.
- Update `SoundsTab.kt` to show tooltips for playback controls.

### 2. Full-Width Search & Layout (@software-engineer)
- Modify `AssetBrowserTab.imgui` to ensure the search bar and refresh button span the entire available width of the window.
- Use `ImGui.calcItemWidth()` and `ImGui.getCursorPosX()` or `ImGui.pushItemWidth(-30f)` to make the search bar flexible.

### 3. Dynamic Grid Columns (@software-engineer)
- In `AssetBrowserTab.imgui`, replace the hardcoded column count (currently 4) with a dynamic calculation:
  ```kotlin
  val itemWidth = 120f // Adjust based on your item size
  val availableWidth = ImGui.getContentRegionAvailX()
  val numColumns = Math.max(1, (availableWidth / itemWidth).toInt())
  ```
- Use `numColumns` in `ImGui.beginTable`.

### 4. Refactor Sounds Tab (@software-engineer)
- **Engine Changes (`SoundBuffer.kt`):**
  - Add a `durationInSeconds: Float` property to `SoundBuffer`.
  - Calculate duration during loading for both OGG and WAV.
    - OGG: `samples / channels / sampleRate`
    - WAV: `totalBytes / (channels * bitsPerSample / 8) / sampleRate`
- **UI Changes (`SoundsTab.kt`):**
  - Add a "Music" icon (suggest adding `const val MUSIC = "\uf001"` to `Icons.kt` if available, or use `Icons.PLAY`).
  - Display the duration next to the icon.
  - Replace text buttons ("▶ Play", "⏹ Stop") with icon-only buttons using `Icons.PLAY` and `Icons.STOP`.
  - Improve the layout:
    - Top: Icon + Duration.
    - Middle: Play/Stop button (centered).
    - Bottom: Filename (wrapped).

### 5. Shared Asset Item Styling (@software-engineer)
- Ensure all tabs (`AnimationsTab`, `TexturesTab`, `PrefabsTab`, `SoundsTab`) use a consistent item size and padding for the grid.
