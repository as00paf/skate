# 📊 PAFSK8 UI Report
**Date:** January 30, 2026
**Framework:** Dear ImGui (Kotlin/LWJGL bindings)

## 1. Overview
The project utilizes Dear ImGui for both the main level editor interface and runtime debugging tools. The UI logic is decentralized: specific `Component` classes implement an `imgui()` method, which is called recursively for the selected object in the scene, while standalone windows are managed by the scene initializer or specific managers.

## 2. Main Windows

### 2.1 Skate Lab (Level Editor)
**Location:** `src/main/kotlin/com/pafoid/skate/engine/scenes/editor/LevelEditorSceneInitializer.kt`
**Type:** Dedicated Window (`ImGui.begin("Skate Lab")`)

**Features:**
*   **Proportions Validation:** Real-time display of the skateboard length and skater height in world units (meters), comparing them against target values (0.80m Board, 1.80m Skater).
*   **Object Resets:** A "Reset Skateboard" button that teleports the skateboard and skater back to the spawn point (0, 2, 0) and zeroes out velocities.
*   **Guidance:** Text hints directing users to other tools (e.g., Prefabs window).

**Progress:**
*   [x] Basic Layout
*   [x] Entity Access (finding "Skateboard"/"Skater" by name)
*   [x] Physics Reset Logic
*   [ ] Modular Toolbar (currently hardcoded buttons)

### 2.2 Skater Debug
**Location:** `src/main/kotlin/com/pafoid/skate/engine/scenes/components/PlayerController.kt`
**Type:** Dedicated Window (`ImGui.begin("Skater Debug")`)

**Features:**
*   **State Monitoring:** Displays the current `PlayerState` (Riding, Walking, etc.).
*   **Stance Info:** Shows Preferred Stance (Regular/Goofy), Current Stance (Regular/Fakie/Switch/Nollie), and Switch status.
*   **Physics Data:** Real-time grounded state and linear velocity vector (X, Y, Z).
*   **Controls:** Buttons to toggle "Switch" mode and "Preferred Stance" for testing animation/physics mirroring.

**Progress:**
*   [x] Real-time Data Feed
*   [x] Interactive State Toggles
*   [ ] Graph Visualization (Velocity over time)

## 3. Component Inspectors
These UIs appear within the "Inspector" window (managed by the Editor) when a GameObject with these components is selected.

### 3.1 Transform
**Location:** `src/main/kotlin/com/pafoid/skate/engine/scenes/components/Transform.kt`
**Features:**
*   **TRS Control:** Draggable float fields for Translation, Rotation (Euler), and Scale.
*   **Sensibility:** Custom drag speeds for rotation/scale for finer control.

### 3.2 Entity (Material Editor)
**Location:** `src/main/kotlin/com/pafoid/skate/engine/entities/Entity.kt`
**Features:**
*   **Material Tree:** Collapsing header listing all model parts.
*   **PBR Controls:**
    *   Texture preview (Base Color).
    *   Color Picker for tinting.
    *   Sliders for Roughness and Metallic factors.
*   **UV Scaling:** Global texture scale slider.

### 3.3 Animator (Timeline)
**Location:** `src/main/kotlin/com/pafoid/skate/engine/animation/Animator.kt`
**Features:**
*   **Clip Selection:** Dropdown combo box to switch between available animations (e.g., "Walk", "Jump", "Ride").
*   **Scrubbing:** Slider timeline to manually scrub through the animation frame-by-frame (pauses playback automatically).
*   **Playback Controls:** Play/Pause and Reset buttons.
*   **Metadata:** Displays total duration of the current clip.

### 3.4 Trick Analyzer (Overlay)
**Location:** `src/main/kotlin/com/pafoid/skate/engine/scenes/components/TrickAnalyzer.kt`
**Features:**
*   **Heads-Up Display:** Shows the name of the last performed trick (e.g., "Kickflip", "BS 180").
*   **Air Stats:** Displays real-time rotation vector (Pitch, Yaw, Roll) while airborne.

## 4. Summary & Recommendations
The UI system is functional and provides critical debugging data.

**Recommendations:**
1.  **Centralized Manager:** The "Skate Lab" window logic is inside `SceneInitializer`. It should likely be moved to a dedicated `EditorSystem` or `GuiLayer` class to persist across scene reloads.
2.  **Visual Polish:** The `TrickAnalyzer` output is raw text. It could be enhanced with a "Toast" style notification system for trick landings.
3.  **Input Blocking:** Ensure ImGui captures mouse/keyboard events to prevent game inputs (jumping/steering) while typing in text fields or adjusting sliders.
