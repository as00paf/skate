# Running the Skate agent herd with herdr

[herdr](https://herdr.dev) runs coding agents in persistent terminal panes and tracks whether each one is `working`, `blocked` or `idle`. These scripts start one agent per engine domain from `GameEngine.md`, plus a `skate-lead` orchestrator that dispatches tasks to them.

## Files

| Path | Purpose |
|------|---------|
| `GameEngine.md` | Backlog: domain sections, task IDs (`REN-01`, `PHY-03`, ...), ownership map |
| `.github/agents/<agent>.agent.md` | Copilot CLI custom agents (**source of truth**) |
| `.opencode/agents/<agent>.md` | OpenCode agents, generated by `sync-agents.sh` (don't edit) |
| `tools/herdr/herd.sh` | Creates the herdr layout and starts the agents |
| `tools/herdr/sync-agents.sh` | Regenerates the OpenCode agents from the Copilot ones |

Agents: `skate-lead`, `skate-render`, `skate-assets`, `skate-ecs`, `skate-physics`, `skate-animation`, `skate-audio`, `skate-input`, `skate-gameplay`, `skate-gameui`, `skate-scripting`, `skate-online`, `skate-editor`, `skate-tooling`, `skate-qa`.

## Requirements

- A running herdr server (`herdr status server`), plus `jq` and `git`.
- `copilot` (default) or `opencode` on `PATH`.
- Run from WSL. Agents build with `cmd.exe /c gradlew.bat ...` because the LWJGL/Bullet natives are Windows-only.
- New panes must reach a shell prompt without waiting for input. If your shell startup prompts (for example `ssh-add` asking for a passphrase), skip that step inside herdr with `[[ $HERDR_ENV == 1 ]] || ssh-add ...`.

## Usage

```bash
tools/herdr/herd.sh                          # lead + all domains, tabs in the "skate" workspace
tools/herdr/herd.sh render physics           # lead + selected domains
tools/herdr/herd.sh --no-lead qa             # one domain agent only
tools/herdr/herd.sh --kind opencode ecs      # OpenCode instead of Copilot CLI
tools/herdr/herd.sh --worktrees render ecs   # isolated git worktree per domain
tools/herdr/herd.sh --no-start               # layout only
tools/herdr/herd.sh render -- --allow-all-tools   # extra args for the agent CLI
```

The script is idempotent: agents that are already running (by herdr name) are skipped.

- **Copilot CLI:** started as `copilot --agent skate-<domain>`.
- **OpenCode:** The TUI has no `--agent` flag, so the script sets `OPENCODE_CONFIG_CONTENT='{"default_agent":"skate-<domain>"}'` in the pane and starts `opencode --standalone`. The standalone private server reads that environment variable; the shared background service would not.
- **`--worktrees`:** Each domain gets `agents/<domain>` checked out in `../skate-worktrees/<domain>`, opened as its own herdr workspace grouped with the repo. The worktrees stay on the Windows drive so `gradlew.bat` works. Worktrees only contain committed files, so **commit `.github/` (agents + `copilot-instructions.md`) and `.opencode/agents/` first**.

## Driving the herd

Talk to the lead and let it dispatch:

```bash
herdr agent prompt skate-lead "Plan the next round from GameEngine.md and dispatch ready P0 tasks."
```

Or drive the agents yourself:

```bash
herdr agent list
herdr agent prompt skate-physics "Work on PHY-01 from GameEngine.md." --wait --timeout 3600000
herdr agent read skate-physics --source recent-unwrapped --lines 120
herdr agent wait skate-render --until blocked --timeout 600000
```

Every domain agent ends its turn with machine-readable status lines, which the lead parses:

```
NEEDS ECS: <cross-domain request>         (optional)
DONE PHY-01: <summary> (tests: <command>)
BLOCKED REN-04: <reason>
```

Only `skate-lead` edits task state in `GameEngine.md`. In worktree mode it also merges the `agents/<domain>` branches.

## Integration and PRs

- `tools/herdr/integrate.sh <round> <domain...>` merges `agents/<domain>` branches into `integration/<round>` (worktree `../skate-worktrees/integration`) and runs the tests.
- Skills `herdr-dispatch` and `integrate-round` (in `.github/skills/` and mirrored in `.opencode/skills/`) tell `skate-lead` how to dispatch, approve dialogs, and open/merge PRs with `gh`.
- `gh` needs a one-time `gh auth login -h github.com -p https -w -s repo,workflow`.

## Editing agents

1. Edit `.github/agents/<agent>.agent.md`. Quote the `description` value, because YAML breaks on `: `.
2. Run `tools/herdr/sync-agents.sh` (`herd.sh --kind opencode` also runs it automatically).
3. For a new domain, add it to `ALL_DOMAINS` in `herd.sh`, the ownership map in `GameEngine.md`, and the table in `skate-lead.agent.md`.
