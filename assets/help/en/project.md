# Project

The Project window is the file browser of your game. It shows the folders and files inside the current project, and it is the place where you organise scenes, scripts, textures, models and sounds.

## What it is

A project is a normal folder on your computer. The Project window displays its contents as a tree, with a search field at the top and a status bar at the bottom that counts files, folders and total size.

The window is not the same as the [Asset Browser](asset_browser.md): the Project window shows every file, including scripts and configuration files, while the Asset Browser shows ready-to-use assets grouped by type.

## How to use it

1. Type in the search field to filter the tree by name.
2. Click a folder to expand or collapse it.
3. Double-click a scene to open it, a script to open it in the [Script Editor](script_editor.md), or a file to use the default action.
4. Right-click empty space for **New Folder** and **New File**. Right-click a file or folder for **Rename**, **Delete**, **Show in Explorer**, **Copy Path**, and, for assets, **Re-import**.
5. Right-click a scene or asset to add it to your favourites. Favourites are listed at the top for quick access.
6. Drag a file into the viewport or onto a component field to use it. For example, drag a texture onto a material, or a sound onto an Audio Source.
7. Watch the status bar: it tells you how many files and folders the project contains and how much space they use.

Files on disk are the truth. If you change a file outside the editor, use the refresh action or reopen the window to see the change.
