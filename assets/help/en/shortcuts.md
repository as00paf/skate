# Keyboard shortcuts

Shortcuts save time, but you never have to use them: every action is also available in a menu or a button. This page lists the default keys. Some shortcuts only work in a particular window, such as the Game Viewport or the Scene Hierarchy.

## General

- **Ctrl+Z**: undo the last action.
- **Ctrl+Y** or **Ctrl+Shift+Z**: redo an action you just undid.
- **Ctrl+X**, **Ctrl+C**, **Ctrl+V**: cut, copy and paste the selection.
- **Ctrl+N**: create a new scene.
- **Ctrl+S**: save the current scene.
- **Ctrl+Shift+S**: save the current scene under another name.
- **Ctrl+O**: open a project.
- **Ctrl+P**: open [Search Everywhere](search.md).
- **F5**: start or stop Play mode.
- **F12**: switch the editor to fullscreen and back.
- **Esc**: deselect the current object.

## Moving in the Game Viewport

- **Middle mouse button + drag**: look around.
- **W**, **A**, **S**, **D**: move forward, left, backward and right.
- **Space**: move up.
- **Left Shift**: move down.
- **Mouse wheel**: zoom in and out.
- **Home**: reset the camera to the starting view.
- **F**: focus the camera on the selected object.

## Gizmos

- **1**: select tool.
- **2**: move tool.
- **3**: rotate tool.
- **4**: scale tool.
- **M**: measure tool.

## Scene Hierarchy

- **Insert**: create an empty object.
- **Delete**: delete the selected object.
- **Ctrl+D**: duplicate the selected object.
- **F2**: rename the selected object.
- **V**: show or hide the selected object.
- **L**: lock or unlock the selected object.
- **Up** and **Down**: move through the list.
- **Home** and **End**: jump to the first or last object.

## Console

- **Ctrl+C**: copy the selected lines when the [Console](console.md) is focused.

## Script Editor

- **Ctrl+S**: save the script and reload it if it is running.
- **Ctrl+F**: find text in the current script.
- **Ctrl+H**: find and replace text.
- **Ctrl+G**: go to a line number.

## Changing shortcuts

Open [Key Bindings](keybindings.md) to choose another key for an action. If two actions use the same key in the same context, the editor shows a conflict warning. Reset a single action or a whole category if you get lost.
